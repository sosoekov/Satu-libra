# Соответствие прототипа элементам формы 1С

Документ сформирован обходом всех состояний прототипа в браузере: все стажёры и этапы, обе вкладки стажёра, пустые состояния, все меню и диалоги.
Имена элементов — значения `data-1c-name`, типы — значения `data-1c` из раздела 3.2 ТЗ.
Обновлён по фазе 7 (`docs/tz-phase7-review.md`): новая левая панель, колонки сводной таблицы, команда-флажок в подменю, цвета этапов.
Обновлён по фазе 8 (`docs/tz-phase8-card-simplification.md`): карточка стажёра одной группой (шапка, сроки и степпер), строка следующего шага с раскрывающейся группой уведомлений, командная панель стажировки справа, вкладка «Подготовка к выходу X/Y» с картинкой статуса, строка умолчаний, тумблер статусов задач, действия с выбранными, таблица задач всегда по блокам. Составная полоса прогресса удалена.
Обновлён по фазе 9 (`docs/tz-phase9-cleanup.md`): карточка стажёра без степпера; новая группа `ГруппаПроцесс` — степпер и строки уведомлений-слоты без цветного фона, второстепенные действия на первой строке; дерево из трёх колонок (наименование, статус, количество); чек-лист из пяти колонок без статуса и сортировки; тумблеры — риск вида, который рисует платформа.

Обозначения: ⚠ check — вероятно реализуемо, проверить на платформе; ⛔ high — нужно нестандартное решение; **НЕ_ПЕРЕНОСИТЬ** — только для прототипа, в дереве показан на своём месте, его содержимое поднято к ближайшей переносимой группе.

Прочие решения прототипа, которые стоит проверить, но которые не помечены риском:

- Подменю и контекстное меню строки (`ПодменюЕщеСтажировка`, `ПодменюДобавитьЗадачу`, `ПодменюДействияСВыбранными`, `КонтекстноеМенюЗадачи`) в прототипе всплывают поверх формы; в 1С это штатные подменю командной панели и контекстное меню таблицы.
- Кнопка «?» (`КнопкаСправка`) показывает и скрывает группу `ГруппаСправка` — управление свойством «Видимость».
- Сворачивание левой панели (`КнопкаСвернутьПанель`) — видимость группы с содержимым панели и кнопки «Развернуть»; ширину 40px задаёт группа с одной кнопкой.
- Команда-флажок «Скрыть подразделения без стажёров» (`КомандаСкрытьПустыеПодразделения` в `ПодменюЛеваяПанель`) — команда формы со свойством `Пометка`, по умолчанию Истина; действие инвертирует пометку и перезаполняет дерево.
- Чипы фильтра и поиска над сводной (`ГруппаЧипФильтра`, `ГруппаЧипПоиска`) — горизонтальные группы с цветом фона и управляемой видимостью. Над таблицами задач и чек-листа строк фильтра нет: состояние видно по тумблеру `ТумблерСтатусЗадач`, у чек-листа фильтра нет (фаза 9, решение 9).
- Открытие стажёра из сводной как в таблице 1С: одиночный клик — только текущая строка, двойной клик и Enter — событие `Выбор`, ↑ ↓ — штатное перемещение.
- Дерево на всю оставшуюся высоту панели — `РастягиватьПоВертикали = Истина` у таблицы-дерева.
- Форма `ФормаЗадачаАП` («Задача адаптационной программы») открывается для новой задачи, задачи АП и задачи шаблона. Задача шаблона открывается из `ФормаДобавитьИзШаблона` (гиперссылка в строке или двойной клик) как вложенная форма в режиме «ТолькоПросмотр»; закрытие возвращает к форме-владельцу. Кнопка `КнопкаОткрытьКарточкуПроверяющего` — штатная кнопка открытия у поля выбора (`КнопкаОткрытия`). Таблица `ТаблицаСсылки` — редактируемая таблица формы по ТЧ СсылкиДляОзнакомления. Наблюдатели (`ПолеНаблюдатели`) — реквизит `СписокЗначений` с пользователями, поле без редактирования текста с кнопками выбора и очистки; пустой список — «Не назначены». Выбор — вложенная форма `ФормаВыборНаблюдателей` (поиск, список с флажками) или `СписокЗначений.ОтметитьЭлементы()`.
- Блок «Аналитика по адаптационной программе» (`ГруппаАналитика`, фаза 10, раздел 3) — обычная группа с `Поведение = Свертываемая`, по умолчанию свёрнута, без рамки и фона. Заголовок (`ГруппаАналитикаЗаголовок`, тип `ЗаголовокГруппы` — рисует платформа) «Аналитика по адаптационной программе (N)» задаётся кодом: N — число уведомлений стажёра. При N = 0 группа скрыта. Состояние свёрнута/развёрнута — реквизит формы, общий для всех стажёров. Строки — заранее созданные слоты `ГруппаСтрокаАналитикиN` (картинка по важности, надпись, обычная кнопка). Кнопка уведомления, ведущего в текущий вид (страница и тумблер статусов), скрывается — строка остаётся. Цвет фона строк не меняется: фона нет.
- Действия (фаза 10, 2.1): меню ⋮ и справка — в `ГруппаНавигацияСтажера` справа от «← Все стажёры»; «Продлить срок» / «Отозвать с согласования» — в карточке (`ГруппаДействиеКарточки`); «Печать АП» и основная «Отправить на согласование» — в командной панели вкладки АП (`ГруппаДействияАП`); «Завершить стажировку» — в командной панели вкладки закрытия. Основные действия в блоке аналитики не дублируются основными кнопками.
- Карточка стажёра (`ГруппаКарточкаСтажераШапка`, фаза 10, 2.2) — единственная группа с рамкой: аватар, ФИО и должность; «Наставник» и «Руководитель» гиперссылками; «Даты стажировки» и даты; вторая строка по этапу — полоса срока и «До закрытия: N дней» / «Выход через N дней» / «Стажировка закрыта (отменена) ДД.ММ.ГГ»; при отставании — «Задачи отстают от графика». При узкой форме колонка дат и кнопка действия переносятся второй строкой группы (горизонтальная группа с переносом или две строки групп).
- Дерево подразделений (`ДеревоПодразделений`, фаза 9, 7.2) — три колонки без заголовков: наименование (остаток ширины, отступ уровня и стрелка — штатные для дерева; обрезается только эта колонка), `ДеревоПодразделенийЗначок` — колонка «Статус» 20px (картинка из коллекции: только danger и warning, только у стажёров), `ДеревоПодразделенийКоличество` — колонка «Количество» 32px (число стажёров, только у подразделений, серым, выравнивание вправо).
- Чек-лист (`ТаблицаЧекЛистПодготовки`, фаза 9, 6.3) — пять колонок: «Выполнено» (флажок; заголовок без текста; у пункта «Создать АП» флажок недоступен), «Пункт» (одна строка), «Ответственный» (роль; вторая строка — ФИО или «Выполнил: ФИО»), «Срок» (дата, просроченная цветом danger; вторая строка — «за N дн. до выхода» / «просрочено на N дн.» / «выполнено ДД.ММ»), «Действие». Сортировка всегда по сроку; высота строки — две строки текста.
- Блокировка вкладок (фаза 10, разделы 4 и 5.4) — свойство `ТолькоПросмотр` у таблиц (`ТаблицаЧекЛистПодготовки`, `ТаблицаЧекЛистЗакрытия`, `ТаблицаЗадачАП`) и видимость командных панелей и кнопок изменения; строка с замком — группа с картинкой и надписью (`ГруппаЗапретИзмененияПодготовки`, `ГруппаЗапретИзмененияЗакрытия`), видимость по условию. Подготовка блокируется, если все пункты выполнены и этап — «Стажировка», «Закрытие» или «Закрыта»; все вкладки — после завершения стажировки. Разблокировки нет.
- Страница «Закрытие стажировки» (`СтраницаЗакрытие`, фаза 10, 5.3) — видимость страницы по этапу («Закрытие», «Закрыта»); при появлении страница становится текущей. Заголовок «Закрытие стажировки X/Y» (Y — обязательные пункты) и картинка страницы задаются кодом. Таблица `ТаблицаЧекЛистЗакрытия` — пять колонок как у чек-листа подготовки, у необязательного пункта вторая строка «необязательно», срок — от даты окончания. «Завершить стажировку» — основная кнопка, `Доступность` — нет невыполненных обязательных пунктов; рядом надпись «Осталось обязательных пунктов: N». Форма `ФормаЗавершениеСтажировки` — бывшая «Начать закрытие стажировки».
- Автоматический переход в «Закрытие» (фаза 10, 5.1) — при открытии формы и после продления срока: этап «Стажировка» и до окончания ≤ CLOSE_AVAILABLE_DAYS дней. При переходе чек-лист закрытия заполняется из шаблона, если его ещё нет. Продление дальше порога возвращает этап «Стажировка», чек-лист закрытия сохраняется.
- FT_6: проверяющего и наблюдателей по умолчанию нет (строки умолчаний и формы `ФормаПроверяющиеИНаблюдатели` нет). У задач без своих значений колонки «Проверяющий» и «Наблюдатели» пустые. Новая задача и задачи при создании АП (по шаблону, копированием, «Добавить из шаблона»): проверяющий — из задачи шаблона (при копировании — из копируемой задачи), иначе пусто; наблюдатели — руководитель стажировки, наставник, HR-менеджер и ответственный за подразделение (реквизит `Ответственный` справочника «Подразделения», если не задан — у вышестоящего), без повторов. Заполнение — в «ПриСозданииНаСервере» формы задачи и в обработке создания АП.
- Действия с выбранными (`ГруппаВыбранныеЗадачи`: «Выбрано: N», `ПодменюДействияСВыбранными`, `ГиперссылкаСнятьВыделение`) — видимость группы по количеству отмеченных строк, пересчитывается в «ПриИзменении» флажка `ТаблицаЗадачАПВыбрана`.
- Колонки «Проверяющий» и «Наблюдатели» таблицы задач показывают значения самой задачи; пустая ячейка — не назначены. ФИО везде полные.
