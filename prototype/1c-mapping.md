Прочие решения прототипа, которые стоит проверить, но которые не помечены риском:

- Подменю и контекстное меню строки (`ПодменюЕщеСтажировка`, `ПодменюДобавитьЗадачу`, `ПодменюДействияСВыбранными`, `КонтекстноеМенюЗадачи`) в прототипе всплывают поверх формы; в 1С это штатные подменю командной панели и контекстное меню таблицы.
- Кнопка «?» (`КнопкаСправка`) показывает и скрывает группу `ГруппаСправка` — управление свойством «Видимость».
- Сворачивание левой панели (`КнопкаСвернутьПанель`) — видимость группы с содержимым панели и кнопки «Развернуть»; ширину 40px задает группа с одной кнопкой.
- Команда-флажок «Скрыть подразделения без стажеров» (`КомандаСкрытьПустыеПодразделения` в `ПодменюЛеваяПанель`) — команда формы со свойством `Пометка`, по умолчанию Истина; действие инвертирует пометку и перезаполняет дерево.
- Чипы фильтра и поиска над сводной (`ГруппаЧипФильтра`, `ГруппаЧипПоиска`) — горизонтальные группы с цветом фона и управляемой видимостью. Над таблицами задач и чек-листа строк фильтра нет: состояние видно по тумблеру `ТумблерСтатусЗадач`, у чек-листа фильтра нет (фаза 9, решение 9).
- Открытие стажера из сводной как в таблице 1С: одиночный клик — только текущая строка, двойной клик и Enter — событие `Выбор`, ↑ ↓ — штатное перемещение.
- Дерево на всю оставшуюся высоту панели — `РастягиватьПоВертикали = Истина` у таблицы-дерева.
- Форма `ФормаЗадачаАП` («Задача адаптационной программы») открывается для новой задачи, задачи АП и задачи шаблона. Задача шаблона открывается из `ФормаДобавитьИзШаблона` (гиперссылка в строке или двойной клик) как вложенная форма в режиме «ТолькоПросмотр»; закрытие возвращает к форме-владельцу. Кнопка `КнопкаОткрытьКарточкуПроверяющего` — штатная кнопка открытия у поля выбора (`КнопкаОткрытия`). Таблица `ТаблицаСсылки` — редактируемая таблица формы по ТЧ СсылкиДляОзнакомления. Наблюдатели (`ПолеНаблюдатели`) — реквизит `СписокЗначений` с пользователями, поле без редактирования текста с кнопками выбора и очистки; пустой список — «Не назначены». Выбор — вложенная форма `ФормаВыборНаблюдателей` (поиск, список с флажками) или `СписокЗначений.ОтметитьЭлементы()`.
- Блок «Аналитика по адаптационной программе» (`ГруппаАналитика`, фаза 11, раздел 5) — вертикальная группа с рамкой: заголовок «Аналитика по адаптационной программе (N)» (N — число замечаний) со стрелкой (FT_8: картинки уровня в заголовке нет); справа — кнопки действий по стадии (`ГруппаДействияАналитики`): «Создать АП», «Отправить на согласование», «Начать закрытие стажировки», «Открыть лист согласования» (форма `ФормаЛистСогласования`; на согласовании и после возврата на доработку), «Продлить стажировку», «Отменить стажировку». Основной становится первая показанная из первых трех. Замечания — строки `ГруппаСтрокаАналитикиN` (цветной кружок по важности и надпись, без кнопок — FT_8), видны при развернутом блоке; при N = 0 стрелки нет и блок не раскрывается; группа скрыта, если нет ни замечаний, ни кнопок (этап «Закрыта»). Цвет фона и рамки задается программно по самому критичному замечанию. Состояние развернут/свернут — реквизит формы, общий для всех стажеров.
- FT_8, «Отправить на согласование» — только на этапе «Черновик АП» (АП ни разу не отправлялась или возвращена на доработку). Изменения согласованной АП повторного согласования не требуют: признака «ИзмененаПослеСогласования», замечания и константы `REAPPROVAL_ON_CHANGE` нет.
- FT_8, лист согласования (`ФормаЛистСогласования`) — одна форма для отправки и просмотра. Строка состояния «Обработка не начата / начата ДД.ММ.ГГ ЧЧ:ММ / завершена …»; командная панель `КоманднаяПанельМаршрут`: «Добавить согласующего» (`ФормаВыборСогласующего`, новый шаг «Дополнительное согласование» — в конец маршрута), «Выше» / «Ниже» — только для добавленных шагов и не выше текущего согласующего; удаления нет. Таблица `ТаблицаМаршрут`: флажок, картинка состояния, «Действия» (N. наименование шага), «Сотрудники» (ФИО и подразделение), «Срок» (по ROUTE_STEP_DAYS = 2 дня на шаг). Маршрут по умолчанию: руководитель стажировки → руководитель подразделения (отдела) → руководитель ЦАС → HR-менеджер стажера. В 1С — бизнес-процесс «Согласование» (БСП) или своя ТЧ «МаршрутСогласования» у документа АП. После возврата на доработку форма открывается только для просмотра. Кнопки «Демо: согласовать / отклонить / пропустить шаг» — НЕ_ПЕРЕНОСИТЬ.
- FT_8, права на задачи корпоративного блока: реквизиты (наименование, описание, тип, обязательность, срок, статус, результат, проверяющий, ссылки, блок) меняет только HR-менеджер; остальным в `ФормаЗадачаАП` доступны только наблюдатели (`ГруппаЗадачаКорпБлока` с пояснением), в контекстном меню и массовых действиях «Назначить проверяющего» и «Перенести срок» к ним не применяются (`ГруппаПропускКорпБлока`). В корпоративный блок задачи попадают только из шаблона: в поле «Блок» новой задачи и задачи спец. блока варианта «Корпоративный» нет. В 1С — `ТолькоПросмотр` у элементов по роли пользователя (РольДоступна / функциональная опция) и блоку задачи в «ПриСозданииНаСервере».
- FT_10, страница «Задачи и уведомления»: список задач — только задачи текущего пользователя. Источник «Адаптация персонала» — связанные данные: текущий шаг маршрута согласования АП (тип «Согласовать»), пункты чек-листов подготовки и закрытия, где пользователь ответственный («Выполнить»), задачи АП на проверке у проверяющего («Проверить»), задачи своей АП у стажера («Выполнить»). В 1С — динамический список по задачам бизнес-процессов (БСП «Задача исполнителя») или таблица значений, заполняемая на сервере. Источник «Подбор персонала» в прототипе — тестовые данные.
- FT_10, уведомления: аналитика по стажеру одной строкой (замечания блока аналитики, «выходит через N дней» и что не готово), события адаптации за 7 дней (АП отправлена, согласована, возвращена, начато закрытие, стажировка завершена / отменена, выход на стажировку), адресные события (результат проверки задачи стажеру), тестовые уведомления подбора. «Прочитано» — запись в регистр прочитанных; уведомление по аналитике появляется снова, если набор замечаний изменился.
- FT_10, важность: личная настройка пользователя (регистр сведений), до 6 уровней, цвет флажка по месту уровня; «Установить важность ▾» и отбор «По важности» — по отметкам пользователя.
- FT_11, карточка задачи (`ФормаЗадачаПользователя`) — открывается двойным кликом по строке `ТаблицаМоиЗадачи` (событие «Выбор»). Реквизиты только для просмотра; «Предмет» — гиперссылка: документ подбора (в прототипе — заглушка) или форма `ФормаКарточкаСтажера` в новом окне на странице предмета (пункт чек-листа — «Подготовка к выходу» / «Закрытие стажировки», остальное — «Адаптационная программа»). Команда из карточки выполняет задачу и закрывает форму; «Взять в работу» оставляет ее открытой; «Не согласовано» и «Вернуть на доработку» открывают `ФормаКомментарийРешения` поверх карточки.
- FT_11, кто и когда выполнил — хранится в источнике: у задачи подбора (Выполнил, ДатаВыполнения, Результат, Комментарий), у шага маршрута (ДатаВыполнения, Комментарий; исполнитель — согласующий шага), у пункта чек-листа (Выполнил, ДатаВыполнения), у задачи АП (Выполнил — стажер, ДатаВыполнения; результаты проверок — ТЧ Проверки: Проверяющий, Дата, Результат, Комментарий). Список «Выполненные» строится из этих данных; прежние обработки маршрута после возврата на доработку сохраняются.
- FT_11, `ФормаКарточкаСтажера` — та же карточка стажера, что в основной форме (шапка, аналитика, страницы), без «← Все стажеры» и справки; у каждого открытого окна свое состояние. В 1С — отдельная форма (например, форма объекта «Сотрудник-стажер» или документа АП) с теми же группами, либо общая форма, встроенная в обе. Смена пользователя (демо) закрывает открытые окна.
- FT_12, сортировка (`ТаблицаМоиЗадачиСортировкаИсточник`, `ТаблицаМоиЗадачиСортировкаТипЗадачи`, `ТаблицаУведомленияСортировкаИсточник`) — щелчок по заголовку: ▲ по возрастанию представления, повторный — ▼; одна сортировка на таблицу, снимается выбором другой колонки или «Стандартными настройками». Задачи сортируются внутри групп по сроку. Таблица задач — дерево значений, заполняемое кодом: платформенная сортировка по колонке в дереве не работает внутри групп — порядок задается при заполнении (реквизит СортировкаЗадач); у таблицы уведомлений можно использовать платформенную сортировку по колонке.
- FT_12, `ФормаНастройкаКолонок` — имитация платформенной команды «Изменить форму» (меню «Еще» окна): видимость и заголовки колонок открытой таблицы, «Задача» / «Уведомление» и «Действие» скрыть нельзя, «Стандартные настройки». В 1С разработка не нужна: платформа сохраняет пользовательские настройки формы для каждого пользователя. Запрет скрывать колонки — свойство элемента «ПользовательскаяВидимость» / «Видимость» без возможности изменения пользователем (проверить на платформе 8.5).
- FT_14, история выполнения задачи АП — ТЧ «ИсторияВыполнения» задачи (Период, Пользователь, Событие: взята в работу / выполнена / выполнена, отправлена на проверку / проверена / возвращена на доработку / изменен статус, Комментарий); пишется при каждом действии стажера, проверяющего и при смене статуса в карточке. Комментарий стажера к выполнению и дата выполнения — реквизиты задачи, заполняются формой `ФормаВыполнениеЗадачи`.
- FT_15, страница «Подбор персонала» — имитация модуля подбора: работают только сворачивание групп, флажок «Показывать закрытые» и открытие заявки; числа-гиперссылки и кнопки выводят «Еще не реализовано в прототипе». Счетчики: «На согласовании» — заявки в состоянии «На согласовании»; «Истекает срок» — «Согласована» / «Выполняется» со сроком закрытия вакансии не дальше 7 дней или прошедшим; «В работе» — «Согласована» и «Выполняется»; у «Сотрудников в подборе» — сумма требуемого количества тех же заявок; «Нанято» — найдено по плановым заявкам года; «Внеплановые» — сотрудники во внеплановых заявках года, кроме новых и на согласовании. Цветные градиенты карточек — стилем группы (фон-картинка), если градиент не поддерживается — однотонная заливка.
- FT_14, у форм только для просмотра (`ФормаЗадачаПользователя`, `ФормаЗадачаАП` без права изменения) командной панели нет — форма закрывается платформенным крестиком.
- FT_9, видимость по пользователю — в 1С роли и ограничение доступа на уровне записей (RLS) к стажерам и АП: «все» (заместитель руководителя ЦАС, HR-менеджер за ЦАС), «подразделение с подчиненными» (руководитель отдела), «руководитель стажировки = текущий пользователь», «стажер = текущий пользователь». Сотруднику КШ страница «Адаптация персонала» показывает пустую группу (`ДекорацияКабинетКШ`) — свой кабинет позже. Стажеру: `ГруппаЛеваяПанель` и сводная скрыты, стажер выбран сразу; нет «← Все стажеры», меню ⋮, ссылок в шапке (надписи), страниц чек-листов, командной панели и флажков таблицы задач; в блоке аналитики — только просрочка по задачам без кнопок; `ФормаЗадачаАП` только для просмотра, в командной панели — `ФормаЗадачаАПКнопкаВзятьВРаботу` и `ФормаЗадачаАПКнопкаВыполнено` (меняют статус); без АП — `ДекорацияАПЕщеНеСоздана`.
- Действия (фаза 11, 5.3): меню ⋮ и справка — в `ГруппаНавигацияСтажера` справа от «← Все стажеры»; действия по стадии — в строке заголовка блока аналитики; в карточке кнопок нет; «Печать АП» — в строке кнопок вкладки АП рядом с «Добавить ▾»; «Завершить стажировку» — в строке кнопок вкладки закрытия. «Отменить стажировку» — и в блоке аналитики, и в меню ⋮. «Отозвать с согласования» удалена.
- Карточка стажера (`ГруппаКарточкаСтажераШапка`, фаза 11, 4.1) — группа с рамкой из четырех частей, разделенных вертикальными линиями: `ГруппаСтажер` (аватар 56px; ФИО; подразделение — `ГиперссылкаПодразделение`, открывает карточку подразделения; должность и квалификационный уровень через запятую), `ГруппаНаставник` и `ГруппаРуководитель` (подпись сверху, ФИО гиперссылкой снизу), `ГруппаСроки` (картинка-календарь и «Даты стажировки»; картинка-часы и строка по этапу — «Выход через N дней» / «До закрытия: N дней» / «Стажировка закрыта (отменена) ДД.ММ.ГГ»; при отставании — «Задачи отстают от графика» цветом warning). Полос прогресса, бейджа и кнопок нет. При узкой форме `ГруппаСроки` переносится второй строкой группы. Должность с уровнем — функция `ПредставлениеДолжности()`: уровень выводится, только если он из допустимого списка семейства (А1–А7, П1–П7, AERP1–AERP5).
- Дерево подразделений (`ДеревоПодразделений`, фаза 9, 7.2) — три колонки без заголовков: наименование (остаток ширины, отступ уровня и стрелка — штатные для дерева; обрезается только эта колонка), `ДеревоПодразделенийЗначок` — колонка «Статус» 20px (картинка из коллекции: только danger и warning, только у стажеров), `ДеревоПодразделенийКоличество` — колонка «Количество» 32px (число стажеров, только у подразделений, серым, выравнивание вправо).
- Чек-листы (`ТаблицаЧекЛистПодготовки`, `ТаблицаЧекЛистЗакрытия`, фаза 11, 7.2) — шесть колонок: «Выполнено» (FT_20: индикатор — флажок только для просмотра; заголовок без текста; у пункта «Создать АП» серый), «Пункт» (у необязательного пункта закрытия второй строкой «необязательно»), «Ответственный» (только ФИО; если выполнил другой — второй строкой серым «Выполнил: ФИО»), «Срок» (дата; вторая строка — смещение от выхода или окончания, у невыполненного просроченного — «просрочено на N дн.», дата и текст danger), «Дата выполнения (факт)» (ДД.ММ.ГГ у выполненных, пусто у невыполненных), «Действие» (FT_20: «Выполнить ▾» только у ответственного, у выполненных и «На проверке» — пусто; у «В работе» / «На проверке» рядом с названием — бейдж). FT_20: двойной клик / Enter по строке — `ФормаЗадачаЧекЛиста`: страницы «Задача» (название, статус, проверяющий, срок — смещение от даты выхода / окончания, наблюдатели, описание, `ТаблицаСсылки`) и «Выполнение» (`ПолеВыполнил`, `ПолеФактическаяДатаВыполнения`, `ТаблицаИсторияВыполнения`); только просмотр — при блокировке вкладки, у наблюдателя и у пользователя без прав на стажера (`ГруппаЗадачаТолькоПросмотр`). Может быть той же формой, что `ФормаЗадачаАП`, со скрытыми типом, блоком, обязательностью и результатом выполнения. Форма `ФормаЭлементаБиблиотекаСсылок` — стандартная форма элемента справочника (Название, Группа, Ссылка; «Записать и закрыть»), проверка: ссылка без пробелов и не повторяет существующую. Над таблицей — строка кнопок, под ней тумблер «Все | Мои». Сортировка всегда по сроку; высота строки — две строки текста.
- Блокировка вкладок (фаза 10, разделы 4 и 5.4) — свойство `ТолькоПросмотр` у таблиц (`ТаблицаЧекЛистПодготовки`, `ТаблицаЧекЛистЗакрытия`, `ТаблицаЗадачАП`) и видимость командных панелей и кнопок изменения; строка с замком — группа с картинкой и надписью (`ГруппаЗапретИзмененияПодготовки`, `ГруппаЗапретИзмененияЗакрытия`), видимость по условию. Подготовка блокируется, если все пункты выполнены и этап — «Стажировка», «Закрытие» или «Закрыта»; все вкладки — после завершения стажировки. Разблокировки нет.
- Страница «Закрытие стажировки» (`СтраницаЗакрытие`, фаза 10, 5.3) — видимость страницы по этапу («Закрытие», «Закрыта»); при появлении страница становится текущей. Заголовок «Закрытие стажировки X/Y» (Y — обязательные пункты) и картинка страницы задаются кодом. Таблица `ТаблицаЧекЛистЗакрытия` — пять колонок как у чек-листа подготовки, у необязательного пункта вторая строка «необязательно», срок — от даты окончания. «Завершить стажировку» — основная кнопка, `Доступность` — нет невыполненных обязательных пунктов; рядом надпись «Осталось обязательных пунктов: N». Форма `ФормаЗавершениеСтажировки` — бывшая «Начать закрытие стажировки».
- Начало закрытия (фаза 11, 5.4) — автоматического перехода нет. Кнопка `КнопкаНачатьЗакрытиеСтажировки` (этап «Стажировка» и до окончания ≤ CLOSE_AVAILABLE_DAYS дней) открывает `ФормаНачатьЗакрытие` с вопросом; по подтверждению — этап «Закрытие», чек-лист закрытия из шаблона (если его еще нет), видимость и активация `СтраницаЗакрытие`, запись в историю, оповещение «Закрытие стажировки начато». Продление дальше порога при этапе «Закрытие» возвращает этап «Стажировка», чек-лист закрытия сохраняется. В 1С вопрос можно задать и через `ПоказатьВопрос()` без отдельной формы.
- FT_6: проверяющего и наблюдателей по умолчанию нет (строки умолчаний и формы `ФормаПроверяющиеИНаблюдатели` нет). У задач без своих значений колонки «Проверяющий» и «Наблюдатели» пустые. Новая задача и задачи при создании АП (по шаблону, копированием, «Добавить из шаблона»): проверяющий — из задачи шаблона (при копировании — из копируемой задачи), иначе пусто; наблюдатели — руководитель стажировки, наставник, HR-менеджер и ответственный за подразделение (реквизит `Ответственный` справочника «Подразделения», если не задан — у вышестоящего), без повторов. Заполнение — в «ПриСозданииНаСервере» формы задачи и в обработке создания АП.
- Действия с выбранными (`ГруппаВыбранныеЗадачи`: «Выбрано: N», `ПодменюДействияСВыбранными`, `ГиперссылкаСнятьВыделение`) — видимость группы по количеству отмеченных строк, пересчитывается в «ПриИзменении» флажка `ТаблицаЗадачАПВыбрана`.
- Колонки «Проверяющий» и «Наблюдатели» таблицы задач показывают значения самой задачи; пустая ячейка — не назначены. ФИО везде полные.
- Левая панель (фаза 11, раздел 3) — группа `ГруппаЛеваяПанель` с фоном и скруглением, без заголовка: список фильтров `ГруппаФильтры` (FT_8: пять строк, разделитель после «Требуют внимания»; число окрашено цветом картинки), `ПодменюЛеваяПанель` — в строке «Требуют внимания» справа от числа (`ГруппаФильтрТребуютВнимания`), поле поиска с картинкой лупы (`ПолеПоиска`, свойство «КартинкаКнопкиВыбора» или декорация слева), дерево `ДеревоПодразделений` в рамке на оставшуюся высоту; у выбранного стажера в колонке количества — шеврон «›» (условное оформление по текущей строке или картинка в колонке). «Проходят стажировку» — этап «Стажировка» с > CLOSE_AVAILABLE_DAYS дней до окончания; «Ожидают закрытия» — этап «Закрытие» и этап «Стажировка» с ≤ CLOSE_AVAILABLE_DAYS дней.
- Вкладка АП (фаза 11, 6.1): `КоманднаяПанельЗадач` — «Добавить ▾», «Печать АП», справа при выборе строк — `ГруппаВыбранныеЗадачи`; под ней отдельной строкой `ГруппаТумблерСтатусовЗадач`; затем таблица. Колонки «Действие» в таблице задач нет. Сводная: колонка «Требует действия» — тексты замечаний 5.2, должность — с квалификационным уровнем.
