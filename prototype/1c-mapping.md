# Соответствие прототипа элементам формы 1С

Документ сформирован обходом всех состояний прототипа в браузере: все стажёры и этапы, обе вкладки стажёра, пустые состояния, все меню и диалоги.
Имена элементов — значения `data-1c-name`, типы — значения `data-1c` из раздела 3.2 ТЗ.
Обновлён по фазе 7 (`docs/tz-phase7-review.md`): новая левая панель, колонки сводной таблицы, команда-флажок в подменю, цвета этапов.
Обновлён по фазе 8 (`docs/tz-phase8-card-simplification.md`): карточка стажёра одной группой (шапка, сроки и степпер), строка следующего шага с раскрывающейся группой уведомлений, командная панель стажировки справа, вкладка «Подготовка к выходу X/Y» с картинкой статуса, строка умолчаний, тумблер статусов задач, действия с выбранными, таблица задач всегда по блокам. Составная полоса прогресса удалена.
Обновлён по фазе 9 (`docs/tz-phase9-cleanup.md`): карточка стажёра без степпера; новая группа `ГруппаПроцесс` — степпер и строки уведомлений-слоты без цветного фона, второстепенные действия на первой строке; дерево из трёх колонок (наименование, статус, количество); чек-лист из пяти колонок без статуса и сортировки; тумблеры — риск вида, который рисует платформа.
Обновлён по фазе 10 (`docs/tz-phase10-analytics-closure.md`): степпер и блок процесса удалены; уведомления — в сворачиваемой группе `ГруппаАналитика` с числом в заголовке; действия — в карточке и во вкладках; завершённая подготовка — только просмотр; новая страница `СтраницаЗакрытие` с таблицей `ТаблицаЧекЛистЗакрытия`, реквизит `closureChecklist`.
Обновлён по фазе 11 (`docs/tz-phase11-new-style.md`): новый стиль (скругления, таблицы в рамке, кнопки 32px); левая панель без заголовка, меню ⋮ — в строке «Требуют внимания», шесть фильтров (новый «Просроченные»); карточка стажёра с подразделением-гиперссылкой и должностью с квалификационным уровнем, без кнопок; блок аналитики с программным цветом группы и кнопками действий в строке заголовка; начало закрытия — кнопкой `КнопкаНачатьЗакрытиеСтажировки` (форма `ФормаНачатьЗакрытие`); вкладка АП — строка кнопок над тумблером, группы блоков свёрнуты при открытии; чек-листы — колонка «Дата выполнения (факт)», ответственный только ФИО. Строки умолчаний проверяющего и наблюдателей нет (FT_6).
Обновлён по FT_8: фильтр «Просроченные» удалён; в блоке аналитики нет картинки в заголовке, у замечаний — цветные кружки; «Отправить на согласование» — только для черновика (замечание «изменена после согласования» удалено); форма `ФормаЛистСогласования` — маршрут согласования АП со состояниями шагов, добавлением согласующих (`ФормаВыборСогласующего`) и перемещением; права на задачи корпоративного блока (реквизиты меняет только HR-менеджер); структура ЦАС, ответственные, HR и КШ — по данным заказчика.

Обозначения: ⚠ check — вероятно реализуемо, проверить на платформе; ⛔ high — нужно нестандартное решение; **НЕ_ПЕРЕНОСИТЬ** — только для прототипа, в дереве показан на своём месте, его содержимое поднято к ближайшей переносимой группе.

Прочие решения прототипа, которые стоит проверить, но которые не помечены риском:

- Подменю и контекстное меню строки (`ПодменюЕщеСтажировка`, `ПодменюДобавитьЗадачу`, `ПодменюДействияСВыбранными`, `КонтекстноеМенюЗадачи`) в прототипе всплывают поверх формы; в 1С это штатные подменю командной панели и контекстное меню таблицы.
- Кнопка «?» (`КнопкаСправка`) показывает и скрывает группу `ГруппаСправка` — управление свойством «Видимость».
- Сворачивание левой панели (`КнопкаСвернутьПанель`) — видимость группы с содержимым панели и кнопки «Развернуть»; ширину 40px задаёт группа с одной кнопкой.
- Команда-флажок «Скрыть подразделения без стажёров» (`КомандаСкрытьПустыеПодразделения` в `ПодменюЛеваяПанель`) — команда формы со свойством `Пометка`, по умолчанию Истина; действие инвертирует пометку и перезаполняет дерево.
- Чипы фильтра и поиска над сводной (`ГруппаЧипФильтра`, `ГруппаЧипПоиска`) — горизонтальные группы с цветом фона и управляемой видимостью. Над таблицами задач и чек-листа строк фильтра нет: состояние видно по тумблеру `ТумблерСтатусЗадач`, у чек-листа фильтра нет (фаза 9, решение 9).
- Открытие стажёра из сводной как в таблице 1С: одиночный клик — только текущая строка, двойной клик и Enter — событие `Выбор`, ↑ ↓ — штатное перемещение.
- Дерево на всю оставшуюся высоту панели — `РастягиватьПоВертикали = Истина` у таблицы-дерева.
- Форма `ФормаЗадачаАП` («Задача адаптационной программы») открывается для новой задачи, задачи АП и задачи шаблона. Задача шаблона открывается из `ФормаДобавитьИзШаблона` (гиперссылка в строке или двойной клик) как вложенная форма в режиме «ТолькоПросмотр»; закрытие возвращает к форме-владельцу. Кнопка `КнопкаОткрытьКарточкуПроверяющего` — штатная кнопка открытия у поля выбора (`КнопкаОткрытия`). Таблица `ТаблицаСсылки` — редактируемая таблица формы по ТЧ СсылкиДляОзнакомления. Наблюдатели (`ПолеНаблюдатели`) — реквизит `СписокЗначений` с пользователями, поле без редактирования текста с кнопками выбора и очистки; пустой список — «Не назначены». Выбор — вложенная форма `ФормаВыборНаблюдателей` (поиск, список с флажками) или `СписокЗначений.ОтметитьЭлементы()`.
- Блок «Аналитика по адаптационной программе» (`ГруппаАналитика`, фаза 11, раздел 5) — вертикальная группа с рамкой: заголовок «Аналитика по адаптационной программе (N)» (N — число замечаний) со стрелкой (FT_8: картинки уровня в заголовке нет); справа — кнопки действий по стадии (`ГруппаДействияАналитики`): «Создать АП», «Отправить на согласование», «Начать закрытие стажировки», «Открыть лист согласования» (форма `ФормаЛистСогласования`; на согласовании и после возврата на доработку), «Продлить стажировку», «Отменить стажировку». Основной становится первая показанная из первых трёх. Замечания — строки `ГруппаСтрокаАналитикиN` (цветной кружок по важности и надпись, без кнопок — FT_8), видны при развёрнутом блоке; при N = 0 стрелки нет и блок не раскрывается; группа скрыта, если нет ни замечаний, ни кнопок (этап «Закрыта»). Цвет фона и рамки задаётся программно по самому критичному замечанию. Состояние развёрнут/свёрнут — реквизит формы, общий для всех стажёров.
- FT_8, «Отправить на согласование» — только на этапе «Черновик АП» (АП ни разу не отправлялась или возвращена на доработку). Изменения согласованной АП повторного согласования не требуют: признака «ИзмененаПослеСогласования», замечания и константы `REAPPROVAL_ON_CHANGE` нет.
- FT_8, лист согласования (`ФормаЛистСогласования`) — одна форма для отправки и просмотра. Строка состояния «Обработка не начата / начата ДД.ММ.ГГ ЧЧ:ММ / завершена …»; командная панель `КоманднаяПанельМаршрут`: «Добавить согласующего» (`ФормаВыборСогласующего`, новый шаг «Дополнительное согласование» — в конец маршрута), «Выше» / «Ниже» — только для добавленных шагов и не выше текущего согласующего; удаления нет. Таблица `ТаблицаМаршрут`: флажок, картинка состояния, «Действия» (N. наименование шага), «Сотрудники» (ФИО и подразделение), «Срок» (по ROUTE_STEP_DAYS = 2 дня на шаг). Маршрут по умолчанию: руководитель стажировки → руководитель подразделения (отдела) → руководитель ЦАС → HR-менеджер стажёра. В 1С — бизнес-процесс «Согласование» (БСП) или своя ТЧ «МаршрутСогласования» у документа АП. После возврата на доработку форма открывается только для просмотра. Кнопки «Демо: согласовать / отклонить / пропустить шаг» — НЕ_ПЕРЕНОСИТЬ.
- FT_8, права на задачи корпоративного блока: реквизиты (наименование, описание, тип, обязательность, срок, статус, результат, проверяющий, ссылки, блок) меняет только HR-менеджер; остальным в `ФормаЗадачаАП` доступны только наблюдатели (`ГруппаЗадачаКорпБлока` с пояснением), в контекстном меню и массовых действиях «Назначить проверяющего» и «Перенести срок» к ним не применяются (`ГруппаПропускКорпБлока`). В корпоративный блок задачи попадают только из шаблона: в поле «Блок» новой задачи и задачи спец. блока варианта «Корпоративный» нет. В 1С — `ТолькоПросмотр` у элементов по роли пользователя (РольДоступна / функциональная опция) и блоку задачи в «ПриСозданииНаСервере».
- Действия (фаза 11, 5.3): меню ⋮ и справка — в `ГруппаНавигацияСтажера` справа от «← Все стажёры»; действия по стадии — в строке заголовка блока аналитики; в карточке кнопок нет; «Печать АП» — в строке кнопок вкладки АП рядом с «Добавить ▾»; «Завершить стажировку» — в строке кнопок вкладки закрытия. «Отменить стажировку» — и в блоке аналитики, и в меню ⋮. «Отозвать с согласования» удалена.
- Карточка стажёра (`ГруппаКарточкаСтажераШапка`, фаза 11, 4.1) — группа с рамкой из четырёх частей, разделённых вертикальными линиями: `ГруппаСтажер` (аватар 56px; ФИО; подразделение — `ГиперссылкаПодразделение`, открывает карточку подразделения; должность и квалификационный уровень через запятую), `ГруппаНаставник` и `ГруппаРуководитель` (подпись сверху, ФИО гиперссылкой снизу), `ГруппаСроки` (картинка-календарь и «Даты стажировки»; картинка-часы и строка по этапу — «Выход через N дней» / «До закрытия: N дней» / «Стажировка закрыта (отменена) ДД.ММ.ГГ»; при отставании — «Задачи отстают от графика» цветом warning). Должность с уровнем — функция `ПредставлениеДолжности()`: уровень выводится, только если он из допустимого списка семейства (А1–А7, П1–П7, AERP1–AERP5).
- Дерево подразделений (`ДеревоПодразделений`, фаза 9, 7.2) — три колонки без заголовков: наименование (остаток ширины, отступ уровня и стрелка — штатные для дерева; обрезается только эта колонка), `ДеревоПодразделенийЗначок` — колонка «Статус» 20px (картинка из коллекции: только danger и warning, только у стажёров), `ДеревоПодразделенийКоличество` — колонка «Количество» 32px (число стажёров, только у подразделений, серым, выравнивание вправо).
- Чек-листы (`ТаблицаЧекЛистПодготовки`, `ТаблицаЧекЛистЗакрытия`, фаза 11, 7.2) — шесть колонок: «Выполнено» (флажок; заголовок без текста; у пункта «Создать АП» флажок недоступен), «Пункт» (у необязательного пункта закрытия второй строкой «необязательно»), «Ответственный» (только ФИО; если выполнил другой — второй строкой серым «Выполнил: ФИО»), «Срок» (дата; вторая строка — смещение от выхода или окончания, у невыполненного просроченного — «просрочено на N дн.», дата и текст danger), «Дата выполнения (факт)» (ДД.ММ.ГГ у выполненных, пусто у невыполненных), «Действие». Над таблицей — строка кнопок, под ней тумблер «Все | Мои». Сортировка всегда по сроку; высота строки — две строки текста.
- Блокировка вкладок (фаза 10, разделы 4 и 5.4) — свойство `ТолькоПросмотр` у таблиц (`ТаблицаЧекЛистПодготовки`, `ТаблицаЧекЛистЗакрытия`, `ТаблицаЗадачАП`) и видимость командных панелей и кнопок изменения; строка с замком — группа с картинкой и надписью (`ГруппаЗапретИзмененияПодготовки`, `ГруппаЗапретИзмененияЗакрытия`), видимость по условию. Подготовка блокируется, если все пункты выполнены и этап — «Стажировка», «Закрытие» или «Закрыта»; все вкладки — после завершения стажировки. Разблокировки нет.
- Страница «Закрытие стажировки» (`СтраницаЗакрытие`, фаза 10, 5.3) — видимость страницы по этапу («Закрытие», «Закрыта»); при появлении страница становится текущей. Заголовок «Закрытие стажировки X/Y» (Y — обязательные пункты) и картинка страницы задаются кодом. Таблица `ТаблицаЧекЛистЗакрытия` — пять колонок как у чек-листа подготовки, у необязательного пункта вторая строка «необязательно», срок — от даты окончания. «Завершить стажировку» — основная кнопка, `Доступность` — нет невыполненных обязательных пунктов; рядом надпись «Осталось обязательных пунктов: N». Форма `ФормаЗавершениеСтажировки` — бывшая «Начать закрытие стажировки».
- Начало закрытия (фаза 11, 5.4) — автоматического перехода нет. Кнопка `КнопкаНачатьЗакрытиеСтажировки` (этап «Стажировка» и до окончания ≤ CLOSE_AVAILABLE_DAYS дней) открывает `ФормаНачатьЗакрытие` с вопросом; по подтверждению — этап «Закрытие», чек-лист закрытия из шаблона (если его ещё нет), видимость и активация `СтраницаЗакрытие`, запись в историю, оповещение «Закрытие стажировки начато». Продление дальше порога при этапе «Закрытие» возвращает этап «Стажировка», чек-лист закрытия сохраняется. В 1С вопрос можно задать и через `ПоказатьВопрос()` без отдельной формы.
- FT_6: проверяющего и наблюдателей по умолчанию нет (строки умолчаний и формы `ФормаПроверяющиеИНаблюдатели` нет). У задач без своих значений колонки «Проверяющий» и «Наблюдатели» пустые. Новая задача и задачи при создании АП (по шаблону, копированием, «Добавить из шаблона»): проверяющий — из задачи шаблона (при копировании — из копируемой задачи), иначе пусто; наблюдатели — руководитель стажировки, наставник, HR-менеджер и ответственный за подразделение (реквизит `Ответственный` справочника «Подразделения», если не задан — у вышестоящего), без повторов. Заполнение — в «ПриСозданииНаСервере» формы задачи и в обработке создания АП.
- Действия с выбранными (`ГруппаВыбранныеЗадачи`: «Выбрано: N», `ПодменюДействияСВыбранными`, `ГиперссылкаСнятьВыделение`) — видимость группы по количеству отмеченных строк, пересчитывается в «ПриИзменении» флажка `ТаблицаЗадачАПВыбрана`.
- Колонки «Проверяющий» и «Наблюдатели» таблицы задач показывают значения самой задачи; пустая ячейка — не назначены. ФИО везде полные.
- Левая панель (фаза 11, раздел 3) — группа `ГруппаЛеваяПанель` с фоном и скруглением, без заголовка: список фильтров `ГруппаФильтры` (FT_8: пять строк, разделитель после «Требуют внимания»; число окрашено цветом картинки), `ПодменюЛеваяПанель` — в строке «Требуют внимания» справа от числа (`ГруппаФильтрТребуютВнимания`), поле поиска с картинкой лупы (`ПолеПоиска`, свойство «КартинкаКнопкиВыбора» или декорация слева), дерево `ДеревоПодразделений` в рамке на оставшуюся высоту; у выбранного стажёра в колонке количества — шеврон «›» (условное оформление по текущей строке или картинка в колонке). «Проходят стажировку» — этап «Стажировка» с > CLOSE_AVAILABLE_DAYS дней до окончания; «Ожидают закрытия» — этап «Закрытие» и этап «Стажировка» с ≤ CLOSE_AVAILABLE_DAYS дней.
- Вкладка АП (фаза 11, 6.1): `КоманднаяПанельЗадач` — «Добавить ▾», «Печать АП», справа при выборе строк — `ГруппаВыбранныеЗадачи`; под ней отдельной строкой `ГруппаТумблерСтатусовЗадач`; затем таблица. Колонки «Действие» в таблице задач нет. Сводная: колонка «Требует действия» — тексты замечаний 5.2, должность — с квалификационным уровнем.
