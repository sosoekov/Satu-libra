# FT_47. Формат работы при подтверждении выхода; «Дополнить по шаблону»

Требование заказчика. Все, что здесь не упомянуто, работает как в FT_46.

## 1. Требование

1. При подтверждении выхода выбирать формат работы: в офисе, удаленно, смешанный. Поле — под «Наставник стажировки», по умолчанию «В офисе».
2. «В офисе» — в чек-листе есть задачи «Создать заявку на выпуск пропуска (0911)» и «Подготовить рабочее место». «Смешанный» — только пропуск. «Удаленно» — ни той, ни другой задачи.
3. Убрать задачу чек-листа «Подготовить ПО и доступ к внутренним ресурсам подразделения».
4. Кнопку «Заполнить по шаблону» заменить на «Дополнить по шаблону». Шаблоны: «Чеклист ЦАС (общий)» и «Чеклист ОРФП».
   - Задачи шаблона ЦАС: «Создать учетную запись ИСУП»; «Добавить сотрудника в чаты (Болталка ЦАС, чаты проектов и т.д.)».
   - Шаблон ОРФП — задачи ЦАС и дополнительно «Создать УЗ во внутренней системе ОРФП».
5. В окне выбора шаблонов можно посмотреть задачи шаблона, скорректировать их, создать новый шаблон. При создании указываются наименование, подразделение, которому шаблон доступен, и группа лиц, которые редактируют и удаляют шаблон.
6. Задачи, добавленные по шаблону, можно удалить. Предустановленные (создаются при подтверждении выхода) — нельзя.

## 2. Решения, принятые при реализации

1. **Формат работы** — тумблер «В офисе | Удаленно | Смешанный» в форме «Подтверждение выхода» (и в заявке на подбор, и в «Ожидают решения»), сразу под «Наставник стажировки», по умолчанию «В офисе». Формат сохраняется у стажера, выводится в шапке карточки стажера строкой «Формат работы: в офисе / удаленно / смешанный» и после подтверждения не меняется.
2. **Чек-лист по формату.** Пункт «Создать заявку на выпуск пропуска (0911)» создается для форматов «В офисе» и «Смешанный», «Подготовить рабочее место» — только для «В офисе». У демо-стажеров формат «В офисе», их чек-листы прежние.
3. **«Подготовить ПО и доступ к внутренним ресурсам подразделения»** убран из шаблона подготовки и из чек-листов всех демо-стажеров. В чек-листе теперь 7 пунктов (в офисе), 6 (смешанный), 5 (удаленно). Номера остальных пунктов демо-данных не изменились.
4. **Офис-менеджер.** Новый пользователь Ермоленко Анастасия, офис-менеджер, подразделение «Администрация» (ЦАС). Новая роль ответственного «Офис-менеджер» закреплена за ней, как роли КШ, ФЭС и СУП.
5. **«Дополнить по шаблону»** (было «Заполнить по шаблону», которое заменяло весь чек-лист). Окно «Дополнить по шаблону»:
   - список шаблонов, доступных стажеру. Шаблон доступен стажерам своего подразделения и подчиненных: «Чеклист ЦАС (общий)» — всем стажерам ЦАС, «Чеклист ОРФП» — только стажерам ОРФП (Отдел по работе с федеральными проектами). В демо стажеров ОРФП нет, поэтому у демо-стажеров виден только шаблон ЦАС;
   - выбор шаблона переключателем или щелчком по строке; под списком — задачи выбранного шаблона (задача, ответственный, срок);
   - в строке — «Открыть» (просмотр и изменение шаблона); над списком — «Создать шаблон»;
   - «Дополнить» добавляет задачи шаблона к чек-листу. Ответственный — по роли (офис-менеджер — Ермоленко Анастасия, руководитель стажировки — руководитель стажировки стажера). Срок — дата дополнения + срок задачи (3 дня). Задача, которая уже есть в чек-листе (то же название), повторно не добавляется. Сообщение «Чек-лист дополнен по шаблону «…»: N пунктов».
6. **Ответственные в шаблонах:** «Создать учетную запись ИСУП» — офис-менеджер; «Добавить сотрудника в чаты…» и «Создать УЗ во внутренней системе ОРФП» — руководитель стажировки.
7. **Форма «Шаблон чек-листа»** (открывается поверх окна выбора):
   - наименование, подразделение (шаблон доступен стажерам этого подразделения и подчиненных), редакторы (добавить из списка, убрать крестиком), таблица задач (задача, ответственный по роли, срок в днях), «Добавить задачу», удаление задачи;
   - «Сохранить» — проверка: наименование, подразделение, хотя бы один редактор, хотя бы одна задача, срок — целое число дней от 0. Пустые строки задач не сохраняются;
   - «Удалить шаблон» с подтверждением. Задачи, уже добавленные в чек-листы, остаются;
   - пользователь не из редакторов (и не Администратор) видит шаблон только для просмотра: поля недоступны, кнопка «Закрыть».
8. **Права на шаблоны.** Создают шаблоны Стрыгин, Кладова, Сизова и Администратор; у остальных «Создать шаблон» недоступна. Новый шаблон: подразделение по умолчанию — подразделение стажера, редактор — создатель. Редакторы готовых шаблонов — Стрыгин, Кладова, Сизова. Меняют и удаляют шаблон его редакторы и Администратор.
9. **Удаление задач, добавленных по шаблону.** В карточке такой задачи — кнопка «Удалить пункт» с подтверждением. У предустановленных задач и задач, добавленных через «Добавить пункт», кнопки нет. Удаление подчиняется тем же правам и блокировкам, что и изменение чек-листа.
10. Шаблоны хранятся в данных прототипа до перезагрузки страницы. В 1С — справочник шаблонов чек-листа (наименование, подразделение, табличные части «Редакторы» и «Задачи»).
