# FT_25. Форма шаблона АП: наименование, квалификационный уровень, плашки типа, срок в днях, доп. проверяющий, группы по блоку

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_24.

## 1. Требования

1. «Название» → «Наименование».
2. Добавить «Квалификационные уровни» (заполняются не у всех шаблонов):
   - аналитики: А1. Системный аналитик ученик, А2. Младший системный аналитик, А3. Системный аналитик III категории, А4. Системный аналитик II категории, А5. Системный аналитик I категории, А6. Старший системный аналитик, А7. Ведущий системный аналитик, А8. Методолог/бизнес архитектор;
   - программисты: П1. Программист ученик, П2. Младший программист, П3. Программист III категории, П4. Программист II категории, П5. Программист I категории, П6. Старший программист, П7. Ведущий программист, П8. Системный архитектор.
3. Цветные плашки для типа задачи.
4. Срок в колонке — в формате «3 дня».
5. Колонка «Доп. проверяющий» — вводится вручную, если пользователя нет в системе.
6. Группировка задач по блоку — корпоративный и специальный.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Квалификационные уровни | Один уровень; список — по должности шаблона |
| Цвета плашек | Палитра прототипа: Задача — серая, Курс — синяя, Встреча — зеленая, Тест — желтая |
| Доп. проверяющий | В шаблоне и в АП: при создании АП переносится в задачу, в карточке задачи АП его можно изменить |
| Группировка | Как в таблице задач АП: строки групп со сворачиванием, колонки «Блок» нет, «Выше» / «Ниже» — внутри блока |

## 3. Решения, принятые при реализации

1. **«Наименование»** — подпись поля шаблона (имя элемента `ПолеНазваниеШаблона` не менялось).
2. **«Квалификационный уровень»** — поле выбора между «Должность» и «Автор»:
   - «Аналитик» — А1–А8, «Программист» — П1–П8 (код и наименование: «А3. Системный аналитик III категории»);
   - пусто — «Не указан»; у других должностей и «Для всех должностей» поле недоступно («Нет уровней для должности»);
   - при смене должности уровень другой должности сбрасывается;
   - справочник уровней дополнен А8 и П8 (у стажеров по-прежнему показывается код: «Аналитик, А2»).
3. **Тип** — цветная плашка (только в таблице шаблона).
4. **Срок** — «N дней» от даты выхода («1 день», «2 дня», «10 дней»); полный текст «через N дн. после выхода» — в подсказке ячейки.
5. **«Доп. проверяющий»** — строка, вводится вручную:
   - в карточке задачи шаблона — поле рядом со сроком, в таблице шаблона — колонка;
   - при создании АП по шаблону, добавлении из шаблона и копировании АП переносится в задачу АП;
   - в карточке задачи АП — поле под «Проверяющий» (у задач корпоративного блока его меняет только HR, как остальные реквизиты); изменение пишется в историю АП;
   - задачу «Проверить» не получает — его нет в системе.
6. **Группы по блоку** — «Корпоративный блок (N)» / «Специальный блок (N)», щелчок сворачивает группу; «Выше» / «Ниже» переставляют задачу внутри ее блока (у первой и последней задачи блока команда недоступна).
