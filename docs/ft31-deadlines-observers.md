# FT_31. Сроки задач — не в прошлом; наблюдатели — у одной задачи, выбранные наверху, поиск

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_30.

## 1. Требования

1. Запретить выбор прошедших дней в датах выполнения задач.
2. «Действия с выбранными» → «Наблюдатели»: в окне не отмечены уже назначенные наблюдатели. Уже выбранных — наверх с галками, ниже остальные; добавить поиск.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Просроченные задачи, где действует | Сегодня и позже во всех полях срока задач; прежний просроченный срок можно оставить без изменения |
| Наблюдатели у нескольких задач | Массово наблюдателей не назначать: команда — в меню ⋮ строки задачи; массово — только проверяющий |
| Окно выбора из карточки задачи | Так же: выбранные наверху, поиск |

## 3. Решения, принятые при реализации

### 3.1. Сроки задач

1. **Поля:** срок в карточке задачи АП (и новой задачи), срок в карточке задачи чек-листа, «Перенести срок» → «На дату», срок в «Добавить пункт» (чек-листы подготовки и закрытия).
   - в календаре недоступны дни до сегодняшнего (в 1С — «Ограничение даты» поля ввода / проверка при записи);
   - дату, введенную вручную, проверяет форма: «Срок не может быть раньше сегодняшнего дня (ДД.ММ.ГГ)»;
   - у просроченной задачи прежний срок не мешает сохранить другие изменения; изменить его можно только на сегодня и позже.
2. **«Перенести срок» → «На N дней»:** если у какой-то из задач новый срок окажется в прошлом — ошибка «Срок задачи «…» станет ДД.ММ.ГГ раньше сегодняшнего дня» (для нескольких — «Срок N задач окажется раньше…»).
3. **«Добавить пункт»:** срок по умолчанию (день до выхода / день окончания), если он уже прошел, — сегодня.
4. **Не меняется:** сроки, рассчитанные автоматически (создание АП по шаблону, копирование, добавление из шаблона, задачи чек-листа по шаблону), и срок задачи шаблона в днях от выхода.

### 3.2. Наблюдатели

5. **«Действия с выбранными»:** только «Назначить проверяющего», «Перенести срок», «Удалить». Окно массового изменения наблюдателей удалено.
6. **Меню ⋮ строки задачи АП:** «Наблюдатели…» (после «Назначить проверяющего»). Доступно и у задач корпоративного блока (наблюдателей там меняет руководитель, FT_8); недоступно, когда АП нельзя менять.
7. **Окно «Наблюдатели: название задачи»** (`ФормаНаблюдателиЗадачи`):
   - поиск по ФИО или должности;
   - наверху — текущие наблюдатели с галками, под чертой — остальные;
   - порядок задается при открытии окна и не меняется при отметке (строка не «прыгает»);
   - «Выбрано: N»; «Сохранить» — наблюдатели задачи ровно отмеченные, запись в истории АП «Изменена задача «…»: наблюдатели».
8. **Окно «Выбор наблюдателей» из карточки задачи** — так же: выбранные наверху, поиск по ФИО или должности.

### 3.3. Тесты

9. **Добавлен тест f310.** Обновлены f84 и f118 (состав «Действий с выбранными»; перенос срока на 120 дней, чтобы срок не ушел в прошлое).

## 4. Что проверить заказчику

- У давно просроченной задачи «Перенести срок» на несколько дней дает ошибку, если новый срок все еще в прошлом — переносите «На дату».
- Наблюдателей теперь меняют по одной задаче (меню ⋮ строки или карточка задачи).
