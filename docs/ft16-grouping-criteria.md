# FT_16. Группировка сводной таблицы по подразделениям, «Результат выполнения» задачи, страница «Выполнение»

Требования заказчика и ответы на уточняющие вопросы. Всё, что здесь не упомянуто, работает как в FT_15.

## 1. Требования

1. «Адаптация персонала»: в таблице стажёров — группировка по подразделениям в иерархии, как в дереве левой панели.
2. Карточка задачи → «Задача»: вернуть поле «Результат выполнения». Поле описывает критерии приёмки — по ним проверяющий принимает задачу. Разместить справа от описания задачи.
3. Карточка задачи → «Выполнение»: оформить по макету заказчика. Комментарий стажёра — многострочное поле, фактическая дата — поле ввода, ниже черта и «История выполнения».

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Колонка «Подразделение» и сворачивание групп | Колонку убрать, группы сворачиваются |
| Кто заполняет «Результат выполнения» и где он есть | Как описание задачи:<br>- руководитель в карточке задачи; у корпоративного блока — только HR-менеджер;<br>- есть в задачах шаблона, копируется из шаблона в АП;<br>- стажёр и проверяющий видят только для просмотра |
| Можно ли менять фактическую дату выполнения | Нет: оба поля страницы «Выполнение» только для просмотра |

## 3. Решения, принятые при реализации

### 3.1. Сводная таблица «Стажёры»

1. **Строки-группы подразделений** — в иерархии дерева слева: ЦАС → отдел → направление, стажёры — под своим подразделением.
   - В строке группы: стрелка, наименование, число стажёров. Отступ зависит от уровня. В подсказке — полный путь подразделения.
   - Порядок групп — как в дереве.
   - Пустые подразделения не выводятся, независимо от команды «Скрыть подразделения без стажёров».
2. **Колонки:** «Стажёр», «Этап», «Требует действия», «Задачи», «Срок». Колонки «Подразделение» больше нет.
3. **Сворачивание:**
   - щелчок или Enter на строке группы;
   - свёрнутые группы таблицы не зависят от дерева слева;
   - при поиске все группы раскрыты, как в дереве.
4. **Сортировка** по заголовкам — внутри групп, группы остаются на месте.
5. **Отборы левой панели и поиск** действуют как раньше; группы строятся по оставшимся стажёрам.
6. **Клавиатура:** ↑ ↓ переходят между стажёрами, пропуская строки групп; Enter — карточка стажёра.

### 3.2. «Результат выполнения»

7. **Реквизит `criteria`** у задачи АП и у задачи шаблона.
   - На странице «Задача» — многострочное поле справа от «Описания задачи», той же высоты.
   - У новой задачи в пустом поле подсказка «Критерии, по которым проверяющий примет задачу».
8. **Доступность** — как у описания:
   - меняет руководитель;
   - у корпоративного блока — только HR-менеджер;
   - в задаче шаблона, у стажёра, при запрете редактирования АП — только просмотр.

   Изменение поля не записывается в историю изменений АП, как и изменение описания.
9. **Копирование.** Критерии копируются из шаблона при создании АП и при «Добавить из шаблона», при копировании АП у другого стажёра.
10. **Тестовые данные:**
    - критерии заполнены у задач корпоративного блока и у части задач специального блока шаблонов, а также у задач АП с теми же наименованиями;
    - у задач, добавленных в АП вручную, поле пустое.
11. **Комментарий стажёра к выполнению** по-прежнему на странице «Выполнение» (FT_14). Прежнее поле «Результат выполнения задачи стажером» не вернулось — по смыслу это новый реквизит.

### 3.3. Страница «Выполнение»

12. **«Комментарий стажёра к выполнению»** — многострочное поле только для просмотра на сером фоне. Если комментария нет — серая подсказка «Стажёр не оставил комментарий».
13. **«Фактическая дата выполнения»** — поле ввода шириной 200px, только для просмотра. Если задача не выполнена — подсказка «Задача ещё не выполнена».
14. **Ниже** — черта и «История выполнения», без изменений.

### 3.4. Тесты

15. **Тесты:** f140 — новые имена полей страницы «Выполнение»; тесты сводной таблицы — без колонки «Подразделение». Добавлен тест f160.
