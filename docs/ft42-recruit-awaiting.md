# FT_42. «Подбор персонала»: по одной заявке в состоянии, «Ожидает выхода», «Найденные сотрудники»

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_41.

## 1. Требования

1. На вкладке «Подбор персонала» слишком много заявок: оставить по одной в каждом статусе и добавить еще одну со статусом «Ожидает выхода».
2. Добавить в таблицу колонку «Найденные сотрудники». Заполнять только для «Ожидает выхода» (в других состояниях людей еще нет). Заполнить Ковалевым.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Какая заявка «Ожидает выхода» | ЗП-000040 «Программист» (по ней найден Ковалев), было «Закрыта» |
| Заявки, на которые ссылаются задачи подбора | Убрать только из таблицы: остаются в данных и открываются из задач |
| Что с заявкой после решения по Ковалеву | Выход подтвержден — «Закрыта»; при отмене кандидата и «Вернуть» — остается «Ожидает выхода» |
| Как показывать найденного сотрудника | ФИО ссылкой |

## 3. Решения, принятые при реализации

1. **Таблица «Заявки в работе»** — по одной заявке в каждом состоянии (с «Показывать закрытые» — 6 заявок):
   - «На согласовании» — ЗП-000041 «Системный аналитик»;
   - «Согласована» — ЗП-000043 «Тестировщик»;
   - «Выполняется» — ЗП-000039 «Руководитель проектов»;
   - «Ожидает выхода» — ЗП-000040 «Программист» (новое состояние, после «Выполняется»);
   - «Новая» — ЗП-000045 «Специалист по кадрам»;
   - «Закрыта» — ЗП-000026 «Программист».
   Остальные 16 заявок помечены `hidden` (в 1С — отбор списка): в таблице и счетчиках слева их нет, «Предмет» задач подбора по-прежнему открывает их форму. Счетчики «Вакансии в работе», «Сотрудников в подборе», «Ресурсный план», «Показать все (6)» считаются по заявкам таблицы.
2. **Колонка «Найденные сотрудники»** — последняя (`ТаблицаЗаявкиВРаботеНайденныеСотрудники`). Заполнена только у «Ожидает выхода»: ФИО кандидатов по заявке, которые еще не вышли (ожидают решения или отменены), ссылкой (`ТаблицаЗаявкиВРаботеНайденныйСотрудник`). Щелчок — вкладка «Адаптация персонала», карточка кандидата в «Ожидают решения» подсвечивается (как из уведомления). У отмененного — пометка «отменен», щелчок — сообщение «Стажировка кандидата … отменена».
3. **Смена состояния заявки:**
   - HR нашел требуемое количество кандидатов (событие «Исполнено», «Демо: HR нашел кандидата») — «Ожидает выхода» (раньше — «Закрыта»); заявка с найденным кандидатом показывается в таблице, даже если была скрыта;
   - «Подтвердить выход» — заявка «Закрыта» (дата закрытия — сегодня), когда по ней не осталось кандидатов, ожидающих решения;
   - отмена кандидата и «Вернуть» — заявка остается «Ожидает выхода».
4. **Ширины колонок:** «Состояние» — 130 px, числовые — 96 / 110 / 96 px, «Найденные сотрудники» — 190 px (длинное ФИО — с многоточием, полностью — в подсказке).

### 3.1. Дополнение: градиенты карточек и выравнивание количеств

5. **Требование:** градиенты на вкладке сделать вертикальными, цвета: розово-фиолетовый — вверху фиолетовый RGB (216, 200, 255), внизу розовый RGB (253, 228, 255); желто-зеленый — вверху желтый RGB (248, 255, 153), внизу зеленый RGB (208, 255, 132). Цифры в «Требуемое количество», «Кандидатов в проработке», «Найдено» — по центру.
6. **Карточки** «Вакансии в работе» и «Сотрудников в подборе» — вертикальный градиент фиолетовый → розовый, «Ресурсный план» — желтый → зеленый. Фон стал светлым, поэтому текст розово-фиолетовых карточек — темный (основной цвет текста, как у «Ресурсного плана»; было — белый).
7. **Колонки количеств** — заголовки и числа по центру (было — по правому краю).
