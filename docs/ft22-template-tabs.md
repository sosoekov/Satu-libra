# FT_22. Шаблон АП и АП другого стажера — в отдельной вкладке; изменение шаблона

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_21.

## 1. Требования

1. При создании АП по шаблону или копированием у другого стажера — возможность открыть и посмотреть шаблон.
2. Шаблон корректируют те, кто его создал, а также руководители подчиненных подразделений.
3. И шаблоны, и другие АП открываются в отдельной вкладке, рядом с «Начало».

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Руководители каких подразделений корректируют шаблон | Подчиненных автору: руководители подразделений, вложенных в подразделение автора |
| Авторы тестовых шаблонов | «Базовый — для всех должностей» — Стрыгин, «Руководитель проектов» — Кладова, «Аналитик» — Сизова |
| Что можно менять в шаблоне | Реквизиты (название, должность) и задачи: добавить, изменить, удалить, переместить. Созданные АП не меняются |
| Что открывать по АП другого стажера | Только просмотр АП: шапка и задачи, без изменений, чек-листов и аналитики |

## 3. Решения, принятые при реализации

### 3.1. Где открыть

1. **«Выбор шаблона»** (создание АП по шаблону): в каждой строке — ссылка «Открыть».
2. **«Добавить из шаблона»** (вкладка АП): кнопка «Открыть шаблон» рядом с полем «Шаблон» — открывает выбранный шаблон.
3. **«Копирование АП»**: в каждой строке — ссылка «Открыть АП».
4. **Вкладки окна** рядом с «Начало» (как карточка стажера по ссылке «Предмет», FT_11):
   - «Шаблон АП: название» — форма `ФормаШаблонАП`;
   - «Просмотр АП (ФИО)» — форма `ФормаПросмотрАП`;
   - повторное открытие того же шаблона или АП — переход в уже открытую вкладку.
5. **Форма, из которой открыли, остается открытой** на «Начало»: после просмотра шаблона можно вернуться и сразу создать АП. Закрытие вкладки (✕) возвращает на «Начало».

### 3.2. Шаблон АП

6. **Реквизиты:** «Название» (обязательное), «Должность» (список должностей или «Для всех должностей»), «Автор» (только просмотр).
7. **Задачи** — таблица: «Задача», «Блок», «Тип», «Срок» («через N дн. после выхода»), «Проверяющий», «Обязательная». Ширина колонок меняется, как в FT_21.
8. **Командная панель:** «Добавить задачу», «Выше», «Ниже» (для одной отмеченной задачи), «Удалить» (отмеченные, с подтверждением). Справа — число задач.
9. **Задача шаблона** (ссылка или двойной клик) — форма `ФормаЗадачаШаблона`:
   - «Название задачи»*, «Блок», «Проверяющий», «Тип задачи», «Срок, дней от выхода»* (целое число от 0, под полем — «через N дн. после выхода»), «Обязательная», «Описание задачи», «Результат выполнения», «Ссылки для ознакомления» (из библиотеки ссылок, FT_20);
   - «Сохранить» / «Отмена».
10. **Изменения записываются сразу** (как изменения задач на вкладке АП). Уже созданные по шаблону АП не меняются; новые АП создаются по измененному шаблону.
11. **Права:** изменяют автор и руководители подразделений, вложенных в подразделение автора. В тестовых данных:
    - «Базовый» (автор Стрыгин, ЦАС) — все руководители подразделений ЦАС;
    - «Руководитель проектов» (автор Кладова, отдел корпоративного сопровождения) — Кладова и руководители направлений и групп отдела, в том числе Сизова;
    - «Аналитик» (автор Сизова) — только Сизова: у групп ее направления в тестовых данных нет своих руководителей.

    Остальным — только просмотр: строка с замком «Только просмотр. Изменяют шаблон автор и руководители подразделений, подчиненных автору», поля недоступны, командной панели нет; задача шаблона — только просмотр. Вышестоящие руководители автора (например, Стрыгин для шаблона Сизовой) шаблон не меняют.

### 3.3. Просмотр АП другого стажера

12. **Вкладка «Просмотр АП (ФИО)»:** пояснение «Только просмотр…», шапка (ФИО, должность, подразделение, даты, руководитель и наставник), задачи по блокам: «Задача», «Тип», «Срок» (дата и «через N дн. после выхода» от даты выхода этого стажера), «Проверяющий», «Обязательная».
13. **Задача** (ссылка или двойной клик) — карточка задачи АП только для просмотра с пояснением «Просмотр АП другого стажера — изменения недоступны».
14. **Видимость:** открыть можно АП любого стажера из списка копирования (как и раньше, список не зависит от видимости стажеров по FT_9).

### 3.4. Тесты

15. **Добавлен тест f220.**

## 4. Что проверить заказчику

- Изменения шаблона записываются сразу, без кнопки «Записать» (как задачи на вкладке АП). В 1С форма элемента справочника обычно записывается кнопкой «Записать и закрыть» — можно сделать так.
- Создание нового шаблона и удаление шаблона не делали — в требованиях их нет.
- Задачи корпоративного блока в шаблоне меняют те же пользователи, что и остальные задачи (ограничение FT_8 «корпоративный блок меняет только HR» действует только в АП).
