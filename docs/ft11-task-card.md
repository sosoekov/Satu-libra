# FT_11. Карточка задачи

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_10.

## 1. Требования

По двойному клику по задаче во вкладке «Задачи и уведомления» открывается карточка задачи:

1. Наименование.
2. Описание задачи.
3. Автор и подразделение задачи, дата создания.
4. Срок выполнения.
5. Ссылка на источник («Предмет»): из какой заявки на подбор или из какой адаптационной программы пришла задача. Заявка открывает заглушку «Еще не реализовано в прототипе». Адаптационная программа открывается в новой вкладке окна клиента — рядом с «Начало»; такие вкладки можно открывать и закрывать.
6. Кнопки выполнения задачи в зависимости от ее типа. При выполнении записывается, кто и когда выполнил задачу.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Что во вкладке «Адаптационная программа …» | Карточка стажера — та же, что в «Адаптация персонала» (шапка, аналитика, страницы), с теми же правами; открывается на странице предмета. Работает и без АП |
| Где смотреть, кто и когда выполнил задачу | Фильтр «Выполненные» в левой панели; выполненная задача открывается в карточке только для просмотра: результат, кто выполнил, дата, комментарий |
| Какие кнопки в карточке, кроме команд типа | «Перенаправить» и «Установить важность» |

## 3. Решения, принятые при реализации

### 3.1. Карточка задачи

1. **Двойной клик по строке** открывает карточку задачи (раньше — переход в раздел «Адаптация персонала»). «Перейти» у уведомлений работает как в FT_10.
2. **Карточка** — модальная форма.
   - Заголовок — глагол типа и предмет.
   - Под заголовком бейджи: источник, тип, «В работе», результат (у выполненной), флажок важности.
   - Реквизиты только для просмотра: «Наименование», «Описание», «Автор», «Подразделение автора», «Дата создания», «Срок выполнения» (с «Просрочено на N дн.» / «Осталось N дней»), «Предмет».
3. **Описание и дата создания:**

   | Задача | Описание | Дата создания |
   |---|---|---|
   | Подбор | Тестовые данные | Тестовые данные |
   | «Согласовать» АП | Стажер, должность, подразделение, дата выхода, число задач, шаг маршрута | Начало шага (результат предыдущего шага или отправка на согласование) |
   | Пункт чек-листа подготовки | Стажер, дата выхода, срок пункта | Начало этапа «Подготовка к выходу» |
   | Пункт чек-листа закрытия | Стажер, дата окончания, срок пункта, обязательность | Начало этапа «Закрытие» |
   | «Проверить» | Стажер, описание задачи АП и результат стажера | Когда стажер отметил «Выполнено» |
   | Задача своей АП у стажера | Описание задачи АП | Согласование АП (начало этапа «Стажировка») |

4. **«Предмет»:**
   - У подбора — документ (например, «Заявка на подбор персонала № ЗП-000041 от 20.07.26»). Нажатие показывает оповещение «Еще не реализовано в прототипе».
   - У адаптации — «Адаптационная программа (ФИО)».
5. **Подвал карточки:**
   - «Установить важность ▾» — уровни пользователя и «Снять важность».
   - «Перенаправить» — та же форма, что в списке. Для задач своей АП у стажера недоступно.
   - Команды типа задачи:
     - «Согласовано» / «Не согласовано»;
     - «Взять в работу» / «Выполнить»;
     - «Ознакомиться»;
     - «Проверено» / «Вернуть на доработку».
   - Главная команда — основная кнопка формы, «Закрыть» — обычная.
6. **Поведение команд:**
   - Команда выполняет задачу и закрывает карточку.
   - «Взять в работу» оставляет карточку открытой с отметкой «В работе».
   - «Не согласовано» и «Вернуть на доработку» открывают форму комментария поверх карточки. После ввода комментария закрываются обе формы.
7. **Escape** сначала закрывает открытое подменю, затем — форму.

### 3.2. Выполненные задачи

8. **Кто и когда выполнил** хранится в данных источника:
   - у задачи подбора — «Выполнил», дата со временем, результат, комментарий;
   - у шага маршрута согласования — дата и время, комментарий; исполнитель — согласующий шага;
   - у пункта чек-листа — «Выполнил», дата и время (записывается и при отметке флажком в чек-листе);
   - у задачи АП — «Выполнил» (стажер) и время, время запроса проверки, список проверок (проверяющий, время, результат, комментарий).

   При повторной отправке АП на согласование прежний маршрут сохраняется, поэтому выполненные согласования не пропадают.
9. **Фильтр «Выполненные»** — отдельной строкой под фильтрами по сроку, с числом выполненных задач пользователя.
   - Список без групп, новые сверху.
   - Флажков выбора нет, «Перенаправить» и «Установить важность» недоступны.
   - В колонке «Срок» — «В срок» / «С опозданием на N дн.».
   - Последняя колонка — «Результат»: бейдж и дата выполнения.
   - Отборы «По источнику», «По типу задачи», «По важности» и поиск действуют и на выполненные; их числа считаются по текущему списку.
10. **Выполненная задача** в «Выполненных» — только по действию пользователя-исполнителя:
    - Согласование: шаг, где пользователь — согласующий. Пропущенные шаги не в счет.
    - Пункт чек-листа, где он ответственный.
    - Своя проверка.
    - Задача своей АП у стажера. Отправленная на проверку — с результатом «На проверке». Возвращенная на доработку снова в работе и из «Выполненных» уходит.
11. **Тестовые данные:**
    - У Стрыгина в «Выполненных» — 2 задачи подбора (новые rt-12, rt-13) и 4 согласования АП из маршрутов Лебедева, Орловой, Поповой, Смирнова.
    - Задаче Смирнова «На проверке» добавлены дата выполнения и запроса проверки.
    - Задачам подбора добавлены описания, даты создания и документы-предметы.
12. **Смена демо-пользователя** сбрасывает фильтр на «Все задачи».

### 3.3. Вкладки окон клиента

13. **Вкладки** — строка вкладок клиента: «Начало» и открытые формы «Адаптационная программа (ФИО)». Длинное название — с многоточием, полное — в подсказке. У вкладки — «✕».
14. **Открытие по «Предмету»:**
    - Повторное открытие того же стажера активирует уже открытую вкладку и переключает ее на страницу предмета.
    - Страница предмета: пункт чек-листа подготовки — «Подготовка к выходу», пункт закрытия — «Закрытие стажировки», остальное — «Адаптационная программа».
15. **Окно карточки стажера:**
    - Заголовок формы — «Адаптационная программа (ФИО)», «✕» окна закрывает вкладку.
    - Внутри — карточка стажера без «← Все стажеры» и справки; все действия карточки доступны.
    - У каждой вкладки свое состояние (страница, фильтр задач, выбор, свернутые группы); у «Начало» состояние тоже сохраняется.
    - Закрытие активной вкладки возвращает на «Начало».
16. **Кто может открыть:**
    - Стажер по «Предмету» своей задачи (в том числе пункта закрытия) открывает свою АП.
    - Сотрудник КШ разделом адаптации не пользуется (FT_9) — «Предмет» показывает оповещение «Откроется чек-лист закрытия стажера ФИО».
    - Стажер, которого пользователь не видит, — такое же оповещение.
17. **Смена демо-пользователя** закрывает открытые вкладки.
18. **1С:**
    - Вкладки рисует платформа (НЕ_ПЕРЕНОСИТЬ): форма, открытая без блокировки владельца, получает свою вкладку.
    - Окно карточки стажера — отдельная форма `ФормаКарточкаСтажера` с тем же составом групп, что в основной форме (см. `prototype/1c-mapping.md`).
