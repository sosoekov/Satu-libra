# FT_14. Карточка задачи: комментарий стажера и история выполнения

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_13.

## 1. Требования

1. «Задачи и уведомления»: в колонке «Задача» не показывать наименование шага маршрута.
2. В карточке задачи убрать отдельную кнопку «Закрыть» — есть крестик в заголовке формы.
3. «Адаптация персонала» → «Адаптационная программа»: убрать из таблицы задач значок «Открыть в Forus Team» — команда на форме не нужна.
4. Колонку «Результат» переименовать в «Комментарий к выполнению». Если задача выполнена и стажер оставил комментарий — значок диалога, как раньше.
5. В карточке задачи — поле «Комментарий стажера к выполнению», отделенное чертой от основной карточки. Там же фактическая дата выполнения (когда стажер нажал «Выполнено») и история выполнения. Возврат на доработку проверяющим должен быть виден в истории.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Где разместить комментарий, дату и историю | Вкладка «Выполнение»: комментарий стажера и дата, под чертой — таблица истории |
| Как стажер оставляет комментарий | Окно при «Выполнено» с необязательным комментарием; руководитель видит комментарий только для просмотра; поле «Результат» из основной части карточки убирается |
| В какой карточке убрать «Закрыть» | В обеих: карточка задачи на «Задачах и уведомлениях» и карточка задачи АП только для просмотра |
| Вторая строка в колонке «Задача» | Убрать только у «Согласовать» (шаг маршрута); у остальных задач остается |

## 3. Решения, принятые при реализации

### 3.1. Список и таблица задач

1. **«Согласовать» в списке задач** — без второй строки. Шаг маршрута остается в описании карточки задачи.
2. **Без «Закрыть».** В подвале карточки только для просмотра кнопки «Закрыть» нет, пустой подвал не выводится.
   - Где действует: карточка задачи пользователя (открытая и выполненная), карточка задачи АП только для просмотра (АП на согласовании, закрытая стажировка, задача шаблона) и карточка стажера.
   - Где осталось: у стажера — «Взять в работу» / «Выполнено». В остальных формах «Закрыть» осталась (история АП, лист согласования после возврата).
3. **Колонка «Комментарий к выполнению»** (шире прежней, заголовок в две строки).
   - Значок диалога — у задачи, которую стажер отметил «Выполнено» (статусы «Выполнена» и «На проверке»), если у нее есть комментарий. В подсказке — «Комментарий стажера: …».
   - «Открыть в Forus Team» убрана.

### 3.2. Карточка задачи АП

4. **Карточка задачи АП** (существующей) — страницы «Задача» и «Выполнение». У новой задачи и задачи шаблона страниц нет.
   - «Задача» — прежние поля без «Результата выполнения задачи стажером».
   - «Выполнение»:
     - «Комментарий стажера к выполнению» (только просмотр; нет — «Стажер не оставил комментарий»);
     - «Фактическая дата выполнения» — дата и время, когда стажер нажал «Выполнено». Если задача сейчас не выполнена (в том числе возвращена на доработку) — «Задача еще не выполнена», прежние отметки есть в истории;
     - под чертой — «История выполнения»: «Дата и время», «Кто», «Событие», «Комментарий».
5. **Окно «Задача выполнена»** (`ФормаВыполнениеЗадачи`) открывается у стажера по «Выполнено»:
   - в карточке задачи АП;
   - по «Выполнить» в списке задач и в карточке задачи на вкладке «Задачи и уведомления».

   Устройство окна:
   - наименование задачи; у задачи с проверяющим — «Задача уйдет на проверку: ФИО»;
   - необязательное поле «Комментарий к выполнению»;
   - кнопка «Выполнено».

   После «Выполнено» закрываются окно и карточка под ним. Если при повторном выполнении комментарий пустой, остается прежний.
6. **Что записывается в историю:**

   | Событие | Когда |
   |---|---|
   | «Взята в работу» | стажер |
   | «Выполнена» / «Выполнена, отправлена на проверку» | стажер; с его комментарием |
   | «Проверена» | проверяющий |
   | «Возвращена на доработку» | проверяющий; с комментарием |
   | «Изменен статус: А → Б» | смена статуса в карточке задачи АП руководителем |

   Порядок — по времени.
7. **Тестовые данные:**
   - У выполненных задач: «Взята в работу» (за 4 дня до срока), «Выполнена» (за день до срока, с комментарием стажера). Если есть проверяющий — еще «Проверена».
   - У задач в работе — «Взята в работу».
   - У задачи Смирнова «На проверке» — возврат на доработку Стрыгиным 23.07.26 («Приложите файл с результатом задания») и повторная отправка 24.07.26. Этот возврат виден и в «Выполненных» у Стрыгина.
