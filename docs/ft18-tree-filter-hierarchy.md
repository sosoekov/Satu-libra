# FT_18. Дерево подразделений — отбор; «Отображать в иерархии»

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_17.

## 1. Требования

1. Слева убрать ФИО и показывать только структуру предприятия. Щелчок по подразделению работает как фильтр стажеров.
2. Добавить переключатель «Отображать в иерархии», по умолчанию включен:
   - включен — стажеры сгруппированы по подразделениям;
   - выключен — подразделение выводится колонкой, без группировки.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Щелчок по подразделению | Щелчок по строке — отбор (повторный — снять); стрелка — свернуть / развернуть ветку |
| Отбор по подразделению и фильтры по статусу | Действуют вместе; числа фильтров слева и в дереве считаются без учета отбора по подразделению |
| Где переключатель | В строке «Стажеры: N», перед кнопкой справки |

## 3. Решения, принятые при реализации

### 3.1. Дерево подразделений

1. **В дереве только подразделения.** Стажеров, их значков и подсказок нет.
   - Число у подразделения — стажеры с учетом фильтра по статусу и поиска.
   - «Скрыть подразделения без стажеров» работает как раньше.
2. **Щелчок по строке** (или Enter) — отбор стажеров подразделения и всех вложенных:
   - строка подсвечивается, повторный щелчок снимает отбор;
   - над таблицей появляется чип «Подразделение: … ✕» (полный путь — в подсказке), заголовок — «Стажеры: N из M»;
   - отбор действует на таблицу стажеров и на блок «Ожидают решения»;
   - дерево не сокращается — можно сразу выбрать другое подразделение;
   - при открытой карточке стажера щелчок возвращает к списку с отбором.
3. **Стрелка** слева от названия только сворачивает и разворачивает ветку. Клавиши: → развернуть, ← свернуть. У подразделений без вложенных стрелки нет.
4. **Пустой результат** (отбор + фильтр по статусу) — «Нет стажеров по фильтру «…» в подразделении «…»» со ссылками «Сбросить фильтр» и «Показать все подразделения».
5. **Сброс отбора по подразделению:**
   - смена демо-пользователя;
   - «Перейти» к кандидату из уведомления;
   - вход в создание АП из формы «Стажировка оформлена» — чтобы нужная строка не оказалась скрыта.

### 3.2. «Отображать в иерархии»

6. **Флажок-выключатель** ✓ / ✕ с подписью «Отображать в иерархии» — в строке «Стажеры: N», по умолчанию включен. Выбор помнится до перезагрузки страницы (в 1С — сохраняемый реквизит формы).
7. **Включен** — таблица как в FT_16: группы подразделений в иерархии, сортировка внутри групп.
8. **Выключен** — плоский список:
   - колонка «Подразделение» после «Стажер» (название подразделения, полный путь — в подсказке);
   - сортировка по заголовкам — по всему списку;
   - ↑ ↓ переходят по строкам.
