## 2. Подфаза 7.1. Левая панель

### 2.1. Состав сверху вниз

```
┌─ Обзор по подразделениям ──────────── ⋮ ┐
│ ⚠ Требуют внимания                  5  │
│ ─────────────────────────────────────── │
│ ◷ Ожидают АП                        3  │
│ ▣ На согласовании                   1  │
│ ◉ Проходят стажировку               3  │
│ ⚑ Ожидают закрытия                  1  │
│                                         │
│ [Поиск по ФИО или подразделению      ]  │
│                                         │
│ ⌄ ЦАС (8)                               │
│   ⌄ Отдел корпоративного сопровож… (4)  │
│     ⌄ Направление по автоматизац… (2)   │
│         Иванов Петр Сергеевич       ⓘ   │
│         Белова Анна Дмитриевна      ⓘ   │
│   …                                     │
│   (дерево занимает всю оставшуюся высоту)│
│                                         │
│             « Свернуть                  │
└─────────────────────────────────────────┘
```

- Ширина панели — **360px** (было 320).
- Удаляются: карточки 2×2, тумблер «Структура | Требуют внимания», отдельная строка с флажком, строка «Фильтр: … ✕».

### 2.2. Список фильтров

Вертикальная группа из пяти строк, высота строки 28px. Строка — горизонтальная группа: иконка 16px, подпись, число справа.

| Строка | Кого показывает | Иконка |
|---|---|---|
| Требуют внимания | Стажёры с хотя бы одним уведомлением warning или danger | danger |
| Ожидают АП | Этапы `found`, `draft` | цвет этапа (раздел 4) |
| На согласовании | `approval` | цвет этапа |
| Проходят стажировку | `active` | цвет этапа |
| Ожидают закрытия | `closing` | цвет этапа |

- Между первой строкой и остальными — разделитель.
- Фильтры взаимоисключающие: активен максимум один.
- Активная строка: фон `--c-bg-selected`, подпись полужирная, после числа — кнопка «✕» (сброс).
- Повторный клик по активной строке тоже сбрасывает фильтр.
- Число в «Требуют внимания» всегда равно счётчику на вкладке «Адаптация персонала (N)».
- Подписи без чисел внутри текста, поэтому склонение не нужно.

### 2.3. Меню ⋮ панели

Подменю с одной командой-флажком «Скрыть подразделения без стажёров» (по умолчанию включена, отметка галочкой слева). В 1С — команда с `Пометка`.

### 2.4. Дерево

- **Высота.** Дерево занимает всю оставшуюся высоту панели (`flex: 1; min-height: 0`), прокрутка внутри — только если узлы не помещаются. В 1С — `РастягиватьПоВертикали = Истина`.
- **Корень.** «ЦАС» остаётся и по умолчанию раскрыт.
- **Отступ** уровня — 14px (было 16px).
- **Подразделения** — полужирные, с числом «(N)». Длинные названия обрезаются многоточием, полное название — в `title`.
- **Стажёры** — полное ФИО обычным начертанием. Цветная точка этапа убирается: этап виден в сводной таблице и в карточке.
- **Маркер уведомления** — только иконка 16px справа (danger — круг с «!», warning — треугольник, info — круг с «i»). Текстовые маркеры («1 просроч.», «Нет АП») убираются. Иконка показывается, только если у стажёра есть уведомление; тип — самого важного уведомления.
- **Подсказка строки** стажёра (`title`): «Этап: Стажировка. Просрочено задач: 3» — этап и текст главного уведомления. `data-1c-risk="check"`: в 1С построчная подсказка в ячейке дерева не штатная, в `1c-mapping.md` предложи замену.
- **Выбранный стажёр** подсвечен `--c-bg-selected`, как раньше.
- Фильтр из 2.2 и поиск применяются одновременно.

## 3. Подфаза 7.2. Сводная таблица

### 3.1. Колонки

| Колонка | Содержимое |
|---|---|
| Стажёр | Полное ФИО — гиперссылка (`data-1c-risk="check"`); под ним серым должность |
| Подразделение | Последний уровень; в `title` — полный путь «ЦАС / Отдел корпоративного сопровождения / Группа внедрений» |
| Этап | Бейдж этапа, цвета по разделу 4 |
| Требует действия | Иконка и текст главного уведомления (3.2). Если уведомлений больше одного — второй строкой серым «ещё N» с правильным склонением. Пусто, если уведомлений нет |
| Задачи | См. 3.3 |
| Срок | См. 3.4 |

Колонка «Просрочено» **удаляется**.

### 3.2. Тексты колонки «Требует действия»

Короткие версии текстов уведомлений из 7.1 основного ТЗ. Тот же текст используется в подсказке строки дерева.

| Уведомление | Текст | Цвет |
|---|---|---|
| АП нет | Создать АП, выход через N дн. | warning |
| Просрочены пункты подготовки | Просрочено пунктов подготовки: N | danger |
| Черновик ≥ 2 дней | Не отправлена на согласование N дн. | warning |
| Возврат на доработку | Возвращена на доработку | danger |
| На согласовании | На согласовании с ДД.ММ | `--c-text-secondary` |
| Изменена после согласования | Изменена после согласования | warning |
| Просрочены задачи | Просрочено задач: N | danger |
| Отставание | Отстаёт от графика | warning |
| Скоро окончание | До окончания N дн. | `--c-text-secondary` |

### 3.3. Колонка «Задачи»

| Этап | Показ |
|---|---|
| `found` без АП | «АП нет» серым |
| `found` с АП, `draft`, `approval` | «N задач» (склонение), без полосы |
| `active`, `closing`, `closed` | Полоса 80px и сразу за ней «58%». Полоса цвета `--c-primary`, при `lag` — `--c-warning`. Если есть просроченные задачи — второй строкой «N просроч.» цветом danger |

### 3.4. Колонка «Срок»

- Первая строка: «Выход ДД.ММ.ГГ» для `found`, «до ДД.ММ.ГГ» для остальных, «закрыта ДД.ММ.ГГ» для `closed`.
- Вторая строка, только если до даты ≤ `CLOSE_AVAILABLE_DAYS` дней: «через N дн.» цветом warning.

### 3.5. Сортировка

- **По умолчанию:** по важности главного уведомления (danger → warning → info → нет уведомлений), внутри группы — по дате из «Срок» по возрастанию.
- Сортировка кликом по заголовкам «Этап» (порядок жизненного цикла), «Требует действия» (как по умолчанию), «Задачи» (по проценту), «Срок». Повторный клик меняет направление.
- У заголовка текущей сортировки — индикатор ▲ или ▼.

### 3.6. Открытие стажёра

Повторяем поведение таблицы 1С:

- одиночный клик по строке только делает её текущей (подсветка), карточку **не** открывает;
- двойной клик по строке или Enter на текущей строке — открывают карточку (в 1С событие `Выбор`);
- ↑ ↓ перемещают текущую строку;
- клик по ФИО-гиперссылке открывает карточку сразу.

### 3.7. Заголовок

- Без фильтра: «Стажёры: 8».
- С фильтром или поиском: «Стажёры: 3 из 8» и рядом чип с названием фильтра и «✕».

### 3.8. Вкладка верхнего уровня

У «Адаптация персонала (5)» — `title` «5 стажёров требуют действия» (через `plural()`).

## 4. Подфаза 7.3. Цвета этапов

Цвет бейджа означает только этап. Срочность выражается только колонкой «Требует действия», иконками в дереве и плашками. Цвета warning и danger в бейджах этапов больше не используются.

Добавить токены:

```css
--c-stage-closing: #4B5563;
--c-stage-closing-bg: #E4E7EC;
```

| Этап | Фон | Текст |
|---|---|---|
| `found` — Подготовка к выходу | `--c-neutral-bg` | `--c-text-secondary` |
| `draft` — Черновик АП | `--c-neutral-bg` | `--c-text-secondary` |
| `approval` — Согласование | `--c-info-bg` | `--c-info` |
| `active` — Стажировка | `--c-success-bg` | `--c-success` |
| `closing` — Закрытие | `--c-stage-closing-bg` | `--c-stage-closing` |
| `closed` — Закрыта | `--c-bg` с рамкой `--c-border` | `--c-text-secondary` |

Применить везде, где есть бейдж этапа: сводная таблица, шапка карточки, иконки фильтров левой панели. Степпер не меняется.

## 6. Приёмка

Все проверки — от свежей загрузки страницы, если не сказано иное.

**Подфаза 7.1**

1. **Высота дерева.** В консоли: высота контейнера дерева ≥ 400px при окне 1600×900 и ≥ 280px при 1366×768 (`getBoundingClientRect().height`).
2. **ФИО не обрезаются.** При 1600×900 для каждой строки стажёра в дереве `scrollWidth <= clientWidth` у элемента с ФИО. Все 8 ФИО видны полностью.
3. **Фильтры.** Клик «Требуют внимания» → в дереве и таблице 5 стажёров: Иванов, Белова, Сидоров, Орлова, Лебедев. Клик «Ожидают АП» при активном «Требуют внимания» → активен только «Ожидают АП», 3 стажёра. «✕» → снова 8.
4. **Меню ⋮.** Снятие «Скрыть подразделения без стажёров» → появляются три пустых подразделения с «(0)».
5. **Корень.** «ЦАС (8)» на месте и раскрыт.

**Подфаза 7.2**

6. **Порядок по умолчанию:** Иванов, Лебедев, Орлова, Белова, Сидоров, Попова, Кузнецова, Смирнов.
7. **Задачи.** У Сидорова и Кузнецовой — «N задач» без полосы. У Лебедева полоса warning-цвета, «58%» вплотную к полосе, второй строкой «3 просроч.». У Смирнова полоса primary.
8. **Срок.** У Поповой «до 30.07.26» и «через 5 дн.» warning-цветом. У Лебедева второй строки нет.
9. **Требует действия.** У Орловой «Просрочено задач: 1» и «ещё 1». У Смирнова пусто.
10. **Открытие.** Одиночный клик по строке Смирнова не открывает карточку, только подсвечивает строку. Enter открывает. Клик по ФИО Лебедева открывает сразу.
