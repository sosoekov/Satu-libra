# FT_15. Вкладка «Подбор персонала»: визуальная имитация

Требования заказчика и ответы на уточняющие вопросы. Всё, что здесь не упомянуто, работает как в FT_14.

## 1. Требования

Визуально сымитировать блок подбора персонала по макету заказчика. Интерактивны только заявки в таблице: они открывают форму заявки. Саму форму заявки сделаем в следующем FT.

Состав по макету:
- **слева** — карточки «Вакансии в работе» и «Сотрудников в подборе» (На согласовании / Истекает срок / В работе, у вакансий ещё «Показать все (N)»);
- кнопки «Создать заявку на подбор вне плана» и «Создать заявку на подбор по плану»;
- карточка «Ресурсный план (год)» (План (согласовано) / Нанято / Внеплановые);
- кнопка «Перейти в "Управление ресурсными планами"»;
- **справа** — панель «Заявки в работе». В ней таблица: значок, «Состояние», «Вакансия», «Требуемое количество», «Кандидатов в проработке», «Найдено». Строки сгруппированы по состоянию, группы сворачиваются;
- **под таблицей** — флажок «Показывать закрытые» и кнопка «Аналитика по открытым вакансиям».

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Стиль | Как на макете: градиентные карточки, серые кнопки, серая панель с таблицей, розовые строки групп |
| Откуда заявки и числа | Связать с задачами подбора: номера заявок — те же, что в задачах и в ссылке «Предмет»; числа в карточках считаются по заявкам |
| Значки в первой колонке | «!» — внеплановая заявка на подбор; круговые стрелки — заявка на замену персонала |
| Остальные элементы и заявка до FT_16 | Числа и кнопки — «Ещё не реализовано в прототипе»; группы сворачиваются; «Показывать закрытые» добавляет группу закрытых заявок; двойной клик по заявке — окно-заглушка «Заявка № …» |

## 3. Решения, принятые при реализации

### 3.1. Данные

1. **Заявки** — `vacancyRequests` в `data.js`, 22 шт.:

   | Состояние | Кол-во |
   |---|---|
   | На согласовании | 3 |
   | Согласована | 7 |
   | Выполняется | 5 |
   | Новая | 3 |
   | Закрыта | 4 |

   - Вакансии и количества групп «Согласована», «Выполняется», «Новая» — по макету.
   - **Номера ЗП-000036…ЗП-000044** совпадают с документами задач подбора, состояние — по смыслу задачи:
     - ЗП-000041, 42, 44 — на согласовании (задачи «Согласовать»);
     - ЗП-000036…40 — выполняются (собеседования, резюме кандидатов, дата выхода);
     - ЗП-000043 — согласована (задача «Ознакомиться»).
   - ЗП-000038 (аналитик ERP) — со сроком закрытия вакансии 20.07.26, как в уведомлении «срок закрытия вакансии прошёл».
   - Авторы заявок — руководители подразделений из справочника пользователей, новых пользователей нет.
2. **Ресурсный план** — `resourcePlan`: 2026 год, согласовано 20 сотрудников (тестовое число).

### 3.2. Страница

3. **Группа «На согласовании».** На макете её нет, но заявки на согласовании есть в задачах. Она идёт первой — эти заявки ждут действия руководителя. Далее порядок как на макете: «Согласована», «Выполняется», «Новая». «Закрыта» — последней, только при флажке «Показывать закрытые».
4. **Счётчики** считаются по заявкам:

   | Счётчик | Как считается |
   |---|---|
   | «На согласовании» | заявки в состоянии «На согласовании» |
   | «Истекает срок» | заявки «Согласована» / «Выполняется», у которых до срока закрытия вакансии не больше 7 дней или срок уже прошёл |
   | «В работе» | заявки «Согласована» и «Выполняется» |
   | «Показать все (N)» | все заявки, включая закрытые |
   | «Сотрудников в подборе» | сумма «Требуемого количества» тех же заявок |
   | «План (согласовано)» | из ресурсного плана |
   | «Нанято» | «Найдено» по плановым заявкам года |
   | «Внеплановые» | сотрудники во внеплановых заявках года, кроме новых и на согласовании |

   Сейчас: вакансии 3 / 2 / 12, всего 22; сотрудники 3 / 6 / 18; план 20, нанято 5, внеплановые 11. Правила — в подсказках чисел.
5. **Таблица.**
   - Нули не выводятся, как на макете.
   - Колонка значков: «!» — красный, круговые стрелки — синие; у заявки могут быть оба.
   - В подсказке строки — номер и дата заявки, подразделение, срок закрытия вакансии (на макете этих колонок нет).
6. **Заглушки.** Числа, «Показать все», обе кнопки создания заявки, «Перейти в "Управление ресурсными планами"» и «Аналитика по открытым вакансиям» показывают «Ещё не реализовано в прототипе». Синей (основной) кнопки на странице нет.
7. **Страница одинакова у всех демо-пользователей,** включая стажёра: разграничения доступа к заявкам в требованиях нет.

### 3.3. Форма заявки (заглушка до FT_16)

8. **Как открыть:** двойной клик или Enter на строке заявки.
9. **Окно:**
   - заголовок — «Заявка на подбор персонала № ЗП-000039 от 14.07.26»;
   - текст — «Форма заявки на подбор персонала ещё не реализована в прототипе: «Руководитель проектов», выполняется.»;
   - кнопка «Закрыть».
10. **Ссылка «Предмет»** в карточке задачи подбора открывает ту же форму поверх карточки, если предмет — заявка. Закрытие возвращает к карточке. Для резюме кандидата и отчётов осталась заглушка «Ещё не реализовано в прототипе».
11. **Заглушка раздела** «Раздел не входит в прототип» удалена: все три вкладки формы теперь реализованы.

### 3.4. Тесты
