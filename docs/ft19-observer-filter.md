# FT_19. Фильтр «Являюсь наблюдателем»

Требования заказчика и ответы на уточняющие вопросы. Всё, что здесь не упомянуто, работает как в FT_18.

## 1. Требования

На вкладке «Задачи и уведомления» — новый фильтр «Являюсь наблюдателем», над «Выполненные».

- Задачи, где пользователь наблюдатель, не появляются в общем списке, пока не выбран этот фильтр.
- Такие задачи нельзя менять и выполнять — только смотреть.
- Если пользователь одновременно наблюдатель и, например, руководитель стажировки или наставник, он может изменять задачу.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Какие задачи в фильтре | Только невыполненные задачи АП, где пользователь в наблюдателях |
| Что открывает двойной щелчок | Карточку задачи АП (страницы «Задача» / «Выполнение»): у наблюдателя без прав — только просмотр, у пользователя с правами — как на вкладке АП |
| Тестовые данные | Два случая: Кладова — только наблюдатель; Стрыгин — наблюдатель и заместитель руководителя ЦАС |

## 3. Решения, принятые при реализации

### 3.1. Фильтр и список

1. **Фильтр «Являюсь наблюдателем»** — после разделителя, над «Выполненные». Число — невыполненные задачи наблюдения.
   - Задачи АП со статусом «Выполнена» и задачи закрытых стажировок в фильтр не попадают.
   - Задача «На проверке» попадает: стажёр её выполнил, но проверки ещё не было.
2. **В общем списке** задач наблюдения нет; число «Мои задачи» не меняется.
3. **Строки фильтра:**
   - тип «Наблюдать», вторая строка — «Наблюдение · стажёр ФИО»;
   - группы по сроку («Просроченные», «Требуют внимания», «Остальные»);
   - колонка «Действие» называется «Статус», в ней статус задачи (Просрочена / В работе / На проверке / Не начата) вместо команд;
   - флажков выбора нет; «Перенаправить задачу» и «Установить важность» недоступны с пояснением «Недоступно для задач, где вы наблюдатель»;
   - поиск и отбор «По источнику» действуют. В отборе «По типу задачи» типа «Наблюдать» нет.

### 3.2. Карточка задачи

4. **Двойной щелчок** открывает карточку задачи АП (`ФормаЗадачаАП`).
5. **Права на изменение** (`canManageTraineeTasks`) — как на вкладке «Адаптационная программа»:
   - пользователь видит стажёра по правилам FT_9 (заместитель руководителя ЦАС, HR-менеджеры, руководитель своего отдела, руководитель стажировки);
   - или он руководитель стажировки, наставник или HR-менеджер этого стажёра.

   Ограничения прежних фаз действуют: корпоративный блок меняет только HR-менеджер, АП на согласовании и закрытая стажировка — только просмотр.
6. **Наблюдатель без прав:**
   - все поля недоступны, кнопок «Сохранить» / «Отмена» нет, закрывается крестиком или Esc;
   - вверху пояснение «Вы наблюдатель задачи — только просмотр. Изменяют задачу руководитель стажировки, наставник и HR-менеджер стажёра»;
   - страница «Выполнение» доступна для просмотра.

### 3.3. Тестовые данные

7. **Кладова** — наблюдатель задач Лебедева («Подготовить анализ конкурентов» — просрочена, «Составить план-график пилотного проекта» — в работе, «Изучить методологию управления проектами компании» — выполнена) и двух задач Смирнова (на проверке, не начата). Это чужие отделы: в фильтре 4 задачи, только просмотр.
8. **Стрыгин** — наблюдатель трёх задач Орловой (в работе, не начата, выполнена). В фильтре 2 задачи; как заместитель руководителя ЦАС он может их изменять.
