# FT_8. Лист согласования, права на корпоративный блок, данные ЦАС

Требования заказчика (сообщение от 29.09.26) и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в фазе 11.

## 1. Требования

1. В заголовке блока «Аналитика по адаптационной программе» значка предупреждения нет. У замечаний в раскрытом блоке — только цветные кружки (danger — красный, warning — желтый, info — синий).
2. Фильтр «Просроченные» в левой панели удален.
3. «Отправить на согласование» — только если АП еще ни разу не отправлялась на согласование.
4. Реквизиты задач корпоративного блока меняет только HR-менеджер. Удалить задачу из корп. блока можно; добавить в корп. блок — только задачи из шаблона. Для спец. блока ограничений нет.
5. «Отправить на согласование» открывает окно с согласующими, оформленное как список действий бизнес-процесса 1С: серый крест — шаг пропущен, синяя стрелка — задача сейчас у согласующего, зеленая галка — выполнено с положительным результатом, красная галка — с отрицательным. Добавлять согласующих можно, удалять — нет.
6. Структура подразделений ЦАС, ответственные, HR-менеджеры и сотрудник КШ — по списку заказчика.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| АП, возвращенная на доработку, и замечание «изменена после согласования» | Возвращенную — отправить можно; «изменена после согласования» убрать (изменения согласованной АП согласования не требуют) |
| Что руководитель может менять в задаче корп. блока | Только наблюдателей |
| Как показать права HR-менеджера | Демо-переключатель пользователя |
| Текущий пользователь и руководитель стажировки | Новый пользователь Стрыгин Константин Михайлович — руководитель ЦАС (текущий); руководитель стажировки зависит от подразделения. Других пользователей не придумывать |
| Маршрут согласования по умолчанию | Руководитель стажировки → руководитель подразделения → руководитель ЦАС (Стрыгин) → HR |
| Где еще показывать окно с согласующими | И по «Открыть лист согласования» |
| Куда добавляется согласующий | В конец маршрута; стрелками — выше/ниже; если маршрут стартован — не выше текущего согласующего |

## 3. Решения, принятые при реализации

1. **Руководитель стажировки** — руководитель направления, в котором работает стажер; **наставник** — руководитель соседнего направления того же отдела; **руководитель подразделения** в маршруте — руководитель отдела. Все стажеры распределены по направлениям (в отделах без направлений только один человек — наставника не из кого назначить). В «Отделе отчетности, НСИ и бизнес-процессов», «Отделе по работе с субподрядчиками» и «Отделе по работе с федеральными проектами» стажеров нет; у «Отдела по работе с федеральными проектами» ответственного нет — берется у ЦАС (Стрыгин).
2. **HR-менеджер — свой у каждого стажера** (по двое на каждого из четырех HR). Он — ответственный за пункты HR в чек-листах, наблюдатель новых задач и последний шаг маршрута.
3. **«Мои» в чек-листах** у Стрыгина пусты (он не ответственный за пункты); под демо-пользователем HR показываются пункты этого HR.
4. **Корп. блок, руководитель:** в карточке задачи доступны только наблюдатели, остальные поля — только просмотр с пояснением. В меню строки и массовых действиях «Назначить проверяющего» и «Перенести срок» к задачам корп. блока не применяются (при смешанном выборе — меняются только задачи спец. блока, в окне — пояснение). «Наблюдатели», «Удалить», «Выше / Ниже» — доступны.
5. **В корп. блок — только из шаблона** — для всех пользователей: у новой задачи и у задачи спец. блока в поле «Блок» только «Специальный». HR-менеджер может перевести задачу корп. блока в спец. блок.
6. **Стрелками двигаются только добавленные согласующие**; шаги маршрута по умолчанию не двигаются.
7. **Срок шага** — 2 дня от начала шага (`ROUTE_STEP_DAYS`).
8. **После возврата на доработку** «Открыть лист согласования» показывает завершенную обработку только для просмотра (с красной галкой у отклонившего); «Отправить на согласование» открывает новый маршрут по умолчанию.
9. **Демо-кнопки листа согласования** «согласовать / отклонить / пропустить шаг» (НЕ_ПЕРЕНОСИТЬ) — чтобы показать все состояния шагов. Согласование последнего шага переводит АП в «Стажировку», отклонение — в «Черновик АП» с замечанием «возвращена на доработку».
10. **Кнопки «Стоп» и «Пауза»** из образца 1С не добавлены — управление процессом в ЛК руководителя не требуется.
11. **Длинные названия подразделений** в карточке стажера — одной строкой с многоточием, полное название в подсказке.
