## Цель

Сейчас таблица задач начинается примерно на 740px от верха окна, и на экране 1600×900 видна одна задача. Над таблицей много повторов:

- «65%» показано три раза;
- «11 из 12» — два раза;
- этап — два раза;
- просрочка — три раза.

Задача фазы — убрать повторы и слить элементы так, чтобы при 1600×900 было видно не меньше 8 строк задач. Новых функций не добавляется.

## 2. Подфаза 8.1. Карточка стажёра: шапка и степпер

### 2.1. Раскладка

Одна карточка с рамкой, внутри две строки.

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ ОД  Орлова Дарья Павловна     Наставник: Новиков Павел Сергеевич       15.06.26 – 15.09.26 │
│     Руководитель проектов     Руководитель: Петрова Анна Евгеньевна    Срок   ███░░░ день 41 из 93 │
│                                                                        Задачи ████░░ 65%   │
│ ──────────────────────────────────────────────────────────────────────────────────────── │
│ ✓ Подготовка к выходу ── ✓ Черновик АП ── ✓ Согласование ── ● Стажировка ── ○ Закрытие ── ○ Закрыта │
│                                                             с 15.06.26     с 01.09.26               │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

**Верхняя строка** — горизонтальная группа из трёх частей.

1. **Аватар и имя.** Аватар с инициалами 40px (было 56px). Рядом ФИО (18px, полужирный), под ним должность без префикса «Стажёр на должность:».
2. **Наставник и руководитель** — две строки «Наставник: ФИО» и «Руководитель: ФИО». Подпись серым, ФИО — гиперссылка. Колонка стоит сразу после имени, отступ 32px; пустого пространства между колонками не остаётся.
3. **Даты и полосы** — прижаты вправо:
   - «ДД.ММ.ГГ – ДД.ММ.ГГ»;
   - «Срок» + индикатор + «день 41 из 93»;
   - «Задачи» + индикатор + «65%».

   Обе полосы одного цвета `--c-primary`, подписи слева одной ширины, полосы выровнены по левому краю.

   Вывод третьей строкой — только при отклонении:
   - `lag` → «Отстаёт от графика» цветом `--c-warning`;
   - задачи опережают срок больше чем на `LAG_THRESHOLD` → «Опережает график» цветом `--c-text-secondary`;
   - иначе строки нет.

   Для `found` вместо полос — «Выход через N дней». Для `closed` — «Стажировка закрыта ДД.ММ.ГГ» или «Стажировка отменена ДД.ММ.ГГ».

**Бейдж этапа из шапки убрать.** Этап показывает степпер.

**Нижняя строка — степпер.** Он переезжает внутрь карточки и отделяется от верхней строки линией `--c-border`. Подписи под шагами:

| Шаг | Подпись |
|---|---|
| Текущий | «с ДД.ММ.ГГ» — дата начала этапа. Для `found` — «выход ДД.ММ.ГГ» |
| «Закрытие», если он в будущем и этап `active` | «с ДД.ММ.ГГ» = `endDate − CLOSE_AVAILABLE_DAYS`. Это единственное место, где показывается дата доступности закрытия |
| «Закрыта» при `closed` | Дата закрытия; при отмене — «отменена ДД.ММ.ГГ» |
| Остальные | Без подписи |

Высота карточки при 1600px — не больше 120px.

## 3. Подфаза 8.2. Строка следующего шага

Заменяет плашки уведомлений и командную панель стажировки. Одна горизонтальная группа высотой 44px из двух частей.

```
┌ ⚠ АП изменена после согласования   [Отправить на согласование]   ещё 1 ┐    Продлить срок   Печать АП   ⋮   ?
```

### 3.1. Левая часть — «следующий шаг»

Функция `getNextStep(trainee)` выбирает, что показать. Уведомления делятся на два вида:

- **с действием** — кнопка меняет данные: «Создать АП», «Отправить на согласование», «Начать закрытие стажировки»;
- **навигационные** — кнопка только переключает вид: «Показать», «Показать невыполненные».

Правило выбора:

1. Самое важное уведомление **с действием** (danger → warning → info).
2. Если таких нет — самое важное **навигационное**.
3. Если уведомлений нет — левая часть пустая (группа скрыта).

Отображение:

- фон `--c-*-bg` по типу уведомления, иконка, текст из основного ТЗ 7.1;
- у уведомления с действием — **основная** кнопка; у навигационного — обычная кнопка «Показать»;
- если уведомлений больше одного — гиперссылка «ещё N».

«Ещё N» раскрывает под строкой вертикальную группу с остальными уведомлениями. Каждое — одна компактная строка 32px: иконка, текст, обычная кнопка или гиперссылка действия. Сама ссылка меняется на «Скрыть». В 1С это группа с управляемой видимостью, не всплывающее окно.

Этап `approval`: в левой части info-текст «АП на согласовании с ДД.ММ.ГГ» без кнопки.

Кнопки «Начать закрытие стажировки» в неактивном состоянии больше нет нигде. Когда закрытие доступно, оно приходит в левую часть через уведомление «До окончания стажировки N дн.» с основной кнопкой.

### 3.2. Правая часть — второстепенные действия

Всегда прижата к правому краю. Позиция кнопок не зависит от того, есть ли левая часть.

| Кнопка | Когда видна |
|---|---|
| Отозвать с согласования | `approval` |
| Продлить срок | `active`, `closing` |
| Печать АП | АП существует |
| ⋮ | Всегда: История изменений АП, Открыть документ АП, — , Отменить стажировку |
| ? | Всегда |

Кнопка «Проверяющие и наблюдатели» из панели **убирается**. Точка входа — строка умолчаний над таблицей (5.1).

## 4. Подфаза 8.3. Вкладки стажёра

В название вкладки «Подготовка к выходу» добавляется итог чек-листа:

- всё выполнено: «Подготовка к выходу 7/7» и картинка страницы — галочка цветом success;
- есть просроченные пункты: «Подготовка к выходу 5/7» и картинка — «!» цветом danger;
- иначе: «Подготовка к выходу 2/7» без картинки.

Цветной текст в заголовке страницы в 1С не штатный, поэтому статус передаётся картинкой страницы: `data-1c-risk="check"`.

Название вкладки «Адаптационная программа» не меняется.

## 5. Подфаза 8.4. Вкладка «Адаптационная программа»

### 5.1. Строка умолчаний

Первая строка вкладки, горизонтальная группа:

```
Проверяющий по умолчанию: Новиков Павел Сергеевич     Наблюдатели по умолчанию: Петрова Анна Евгеньевна     Изменить
```

- Подписи серым, значения обычным текстом, «Изменить» — гиперссылка, открывает диалог «Проверяющие и наблюдатели».
- Если наблюдателей больше двух: «Петрова Анна Евгеньевна и ещё 2», полный список в `title`.
- Если проверяющий по умолчанию не задан: «Проверяющий по умолчанию не назначен» цветом `--c-warning` и гиперссылка «Назначить».
- В `closed` гиперссылки нет.

### 5.2. Командная панель таблицы

```
[Все 20 | Просрочено 1 | В работе 2 | Не начато 4 | Выполнено 13]   [+ Добавить ▾]            Выбрано: 2  [Действия с выбранными ▾]  Снять выделение
```

**Тумблер статусов** заменяет тумблер блоков:

- варианты с нулевым количеством скрываются, кроме «Все»;
- порядок: Все, Просрочено, В работе, Не начато, Выполнено;
- по умолчанию выбран «Все»;
- кнопки «Показать» в уведомлениях переключают тумблер на нужный вариант («Просрочено» или, для отставания, «В работе»);
- при удалении, добавлении или смене статуса задачи счётчики пересчитываются. Если выбранный вариант стал нулевым — тумблер переключается на «Все».

Цветное выделение варианта «Просрочено» — желательно, `data-1c-risk="check"`. Если в 1С нельзя, вариант стоит вторым и без цвета.

**Массовые действия:**

- пока не выбрано ни одной строки, их не видно;
- при выборе появляются «Выбрано: N», подменю «Действия с выбранными ▾» (Назначить проверяющего, Наблюдатели, Перенести срок, —, Удалить) и гиперссылка «Снять выделение»;
- в `approval` и `closed` флажки выбора скрыты по правилам основного ТЗ 7.5.4.

Строка «Показаны: … ✕» из основного ТЗ 7.5.1 удаляется: состояние фильтра видно по тумблеру.

### 5.3. Группировка

Таблица **всегда** сгруппирована по блокам. Строка группы:

```
▾ Корпоративный блок    11 из 12   ████████░
```

- название полужирное, «выполнено X из Y», мини-индикатор 80px (`data-1c-risk="check"`, запасной вариант — только текст);
- группы сворачиваются;
- при фильтре по статусу группа без подходящих задач скрывается; «X из Y» в строке группы всегда считается по всем задачам блока, а не по отфильтрованным.

### 5.4. Колонки

| Колонка | Изменение |
|---|---|
| ☐ | Без изменений |
| Задача | Только наименование в одну строку. **Описание убрать** — оно есть в карточке задачи. Длинное наименование обрезается многоточием с `title` |
| Статус | Без изменений |
| Срок | Без изменений |
| Проверяющий | Показывается **только если отличается от проверяющего по умолчанию**, полным ФИО. Иначе ячейка пустая. Приписки «по умолч.» нет. У заголовка `title` «Пусто — проверяющий по умолчанию» |
| Наблюдатели | Так же: только если отличаются от наблюдателей по умолчанию. Одно полное ФИО; если больше — «ФИО и ещё N», полный список в `title` |
| Результат | Без изменений |
| ⋮ | Без изменений |

Высота строки задачи — 32px.

## 8. Приёмка

Окно 1600×900, страница без прокрутки, свежая загрузка, если не сказано иное.

**Плотность и повторы**

1. **Начало таблицы.** Открыть Орлову → `getBoundingClientRect().top` первой строки задачи ≤ 450px.
2. **Строки на экране.** У Орловой полностью видно не меньше 8 строк задач (включая строки групп).
3. **Одна основная кнопка.** Число видимых primary-кнопок на экране ≤ 1 — для каждого из 8 стажёров.
4. **Нет повторов.** У Орловой `document.body.innerText` содержит «65%» ровно один раз и «11 из 12» ровно один раз.
5. **ФИО не сокращены.** Регулярное выражение `/[А-ЯЁ][а-яё]+ [А-ЯЁ]\. ?[А-ЯЁ]\./` по `document.body.innerText` не находит совпадений ни у одного стажёра.

**Шапка и степпер**

6. Бейджа этапа в шапке нет. Степпер внутри карточки. Высота карточки ≤ 120px.
7. У Орловой под шагом «Закрытие» — «с 01.09.26», у Лебедева — «с 06.08.26». Неактивной кнопки закрытия нет ни у кого.
8. У Лебедева под полосами — «Отстаёт от графика». У Смирнова строки вывода нет или «Опережает график» — по данным.

**Строка следующего шага**

9. **Орлова:** слева «АП изменена после согласования» и основная кнопка «Отправить на согласование», «ещё 1». Клик «ещё 1» → под строкой «Просрочено задач: 1» с кнопкой «Показать», ссылка стала «Скрыть». «Показать» → тумблер на «Просрочено», в таблице 1 задача.
10. **Лебедев:** слева «Просрочено задач: 3» с обычной (не основной) кнопкой «Показать», «ещё 1» (отставание).
11. **Смирнов:** левой части нет. Кнопки правой части стоят на тех же координатах x, что у Орловой (±2px).
12. **Попова:** слева «До окончания стажировки 5 дн.» и основная кнопка «Начать закрытие стажировки».
13. **Кузнецова:** слева «АП на согласовании с …» без кнопки, справа «Отозвать с согласования».

**Вкладки и таблица**

14. Вкладка у Орловой — «Подготовка к выходу 7/7» с галочкой, у Иванова — «2/7» с «!».
15. У Смирнова в тумблере нет варианта «Просрочено». Сумма вариантов, кроме «Все», равна «Все».
16. В колонке «Проверяющий» у Орловой заполнены только задачи с проверяющим, отличным от умолчания. Текста «по умолч.» на странице нет.
17. Выбрать 2 строки → «Выбрано: 2», подменю и «Снять выделение» появились. «Снять выделение» → всё скрылось.
18. У Орловой выбрать фильтр «Просрочено», затем через карточку задачи сменить статус этой задачи на «Выполнена» → тумблер сам вернулся на «Все», счётчики пересчитаны.

**Прочее**

19. Демо-переключатель находится в заголовке окна и не перекрывает содержимое при 1366 и 1600.
20. `check1c()` возвращает пустой список. Проверки раздела 10 основного ТЗ и приёмка фазы 7 проходят.

- **Сценарий 5.** Вместо «появилась плашка» — строка следующего шага показывает «АП изменена после согласования».
- **Сценарий 7.** Вместо «info-плашки» — строка следующего шага с основной кнопкой «Начать закрытие стажировки».

## 9. Решения, принятые при реализации

Согласованы с заказчиком до начала работ.

1. **Пункт приёмки 1.** Порог ослаблен до **≤ 560px**. Над содержимым карточки стоят оболочка 1С 8.5, заголовок формы и верхние вкладки (≈ 163px). Ниже по документу идут «← Все стажёры», карточка, строка следующего шага, вкладки стажёра, строка умолчаний, командная панель и заголовок таблицы. При отступах 8px первая задача получается на ≈ 540px. Главным критерием плотности остаётся пункт 2: не меньше 8 полностью видимых строк.
2. **Главное действие этапа без уведомления.** Если уведомлений с действием нет, `getNextStep` показывает главное действие этапа с нейтральным текстом и основной кнопкой. Например, свежий черновик — «Отправить на согласование». Этап «Закрытие» при сроке больше `CLOSE_AVAILABLE_DAYS` — «Начать закрытие стажировки». Навигационные уведомления в этом случае уходят в «ещё N».

Приняты при реализации, вынесены на проверку заказчика в отчётах по подфазам.

3. **Пункт приёмки 1 — фактическое значение.** Первая строка задачи у Орловой — на 559px. Для этого отступы между частями карточки стажёра уменьшены с 16 до 12px, между строками вкладки АП — с 12 до 8px, у командной панели таблицы убрана нижняя рамка: таблица начинается сразу под ней.
4. **Ширина колонок ФИО в таблице задач.** «Проверяющий» и «Наблюдатели» — по 20% ширины таблицы, при ширине окна до 1500px — по 13%, чтобы осталось место для наименования задачи. При 1366px полные ФИО в этих колонках обрезаются многоточием, полное значение — в подсказке.
5. **Наблюдатели в карточке задачи.** Поле «Наблюдатели» следует правилу строки умолчаний: до двух — полные ФИО через запятую, больше — «ФИО и ещё N», полный список в подсказке.
6. **Демо-переключатель в заголовке.** Строка заголовка формы (`ЗаголовокФормы`, НЕ_ПЕРЕНОСИТЬ) больше не скрыта от вспомогательных технологий целиком: скрыты название и декоративные кнопки ⟳ ⋮, а демо-переключатель между ними остаётся интерактивным. Меню этапов раскрывается вниз. Оповещения пользователя остались в правом нижнем углу.
