# FT_20. Чек-листы — карточки задач; библиотека ссылок

Требования заказчика и ответы на уточняющие вопросы. Все, что здесь не упомянуто, работает как в FT_19.

## 1. Требования

1. Чек-лист в 1С 8.5 — визуальное подобие: каждый пункт на самом деле карточка задачи.
   - Кнопка «Выполнить» доступна только исполнителям задачи. У остальных она недоступна, причина — в подсказке.
   - Выполненная задача отмечается галкой в чек-листе.
   - Любую задачу можно открыть и посмотреть, как задачу АП. Карточка похожая, но без части реквизитов.
2. Все ссылки в задачах выбираются из списка — будущего справочника «Библиотека ссылок».
   - Внизу выпадающего списка — «+ Создать», как в классической 1С.
   - У элемента справочника есть название, группа и сама ссылка.

## 2. Ответы на вопросы

| Вопрос | Ответ |
|---|---|
| Какие чек-листы | Оба: подготовка к выходу и закрытие стажировки |
| Команды кнопки | Основная часть — «Выполнить», в меню ▾ — только «Взять в работу». Команд документов в кнопке нет |
| Проверяющий и наблюдатели | Поля есть для единообразия, по умолчанию пустые — никого не подставлять. Меняются как у задач АП. С проверяющим — как у задач АП: «На проверке» и задача «Проверить» |
| Исполнитель и команды документов в карточке | Нет, как на макете |
| Поле ссылки | Поле выбора и комментарий |

## 3. Решения, принятые при реализации

### 3.1. Строка чек-листа

1. **Колонка-флажок — индикатор.** Галка у выполненного пункта, щелчком не меняется.
   - У «Создать АП» индикатор серый: пункт отмечается автоматически при создании АП.
   - В 1С — флажок только для просмотра.
2. **«Выполнить ▾»** — в колонке «Действие».
   - Доступна, если текущий пользователь — ответственный пункта.
   - У остальных недоступна с подсказкой «Выполнить задачу может только ответственный: ФИО».
   - У «Создать АП» подсказка — «Отметится автоматически, когда для стажера будет создана АП».
   - На заблокированной вкладке подсказка — текст блокировки.
   - У выполненных пунктов и пунктов «На проверке» кнопки нет.
3. **Статус рядом с названием:** бейджи «В работе» и «На проверке» (проверяющий — в подсказке).
4. **Выполнение:**
   - без проверяющего — пункт выполнен: галка, дата выполнения (факт), «Выполнил»;
   - с проверяющим — «На проверке», у проверяющего задача «Проверить» на вкладке «Задачи и уведомления»;
   - «Проверено» — пункт выполнен; «Вернуть на доработку» (с комментарием) — снова «В работе»;
   - исполнитель получает уведомление о результате проверки.
5. **Команды документов удалены:** «Создать заявку» (форма заявки 0911), «Открыть Bitrix», «Открыть Forus Team», «Открыть СИТ».
   - Переход во внешние системы — по ссылкам задачи: у пунктов шаблонов есть ссылки «Bitrix24», «Сервис заявок 0911», «Forus Team», «СИТ».
   - Номера уже созданных заявок 0911 в данных сохранились, но в чек-листе не показываются.
6. **Двойной клик или Enter** по строке открывает карточку задачи.

### 3.2. Карточка задачи чек-листа

7. **Заголовок:** «Задача чек-листа подготовки к выходу» или «Задача чек-листа закрытия стажировки». Форма `ФормаЗадачаЧекЛиста`.
8. **Страница «Задача»** — как на макете:
   - «Название задачи» и «Статус»;
   - «Проверяющий» (с кнопкой карточки сотрудника) и «Срок выполнения» (под полем — от какой даты считается);
   - «Наблюдатели»;
   - «Описание задачи»;
   - «Ссылки для ознакомления».

   Типа, блока, обязательности, результата выполнения, исполнителя и команд документов нет.
9. **Страница «Выполнение»:** «Выполнил», фактическая дата выполнения и история выполнения.
   - В истории — взятие в работу, выполнение, отправка на проверку, проверка, возврат, смена статуса вручную, автоотметка «Создать АП».
10. **Изменение:**
    - срок пересчитывается в смещение от даты выхода или окончания стажировки;
    - у стажера без даты выхода срок недоступен;
    - статус «На проверке» требует проверяющего;
    - статус «Создать АП» вручную не меняется.
11. **Права** — как у задач АП (FT_19, `canManageTraineeTasks`). Только просмотр с пояснением вверху, если:
    - вкладка заблокирована (подготовка завершена, стажировка закрыта);
    - пользователь — только наблюдатель;
    - у пользователя нет прав на стажера.

    Кнопки «Сохранить» / «Отмена» в этом случае не выводятся.
12. **Наблюдатели пунктов** видят их в фильтре «Являюсь наблюдателем» (FT_19). Двойной клик открывает карточку задачи чек-листа.

### 3.3. Библиотека ссылок

13. **Справочник** `linkLibrary` с группами `linkGroups`:
    - группы: «Корпоративный портал», «Регламенты и документы», «Обучение», «Внешние системы»;
    - 11 придуманных ссылок;
    - перенесены прежние ссылки задач: «Регламенты на портале», «Корпоративный кодекс» и 5 курсов (по одному элементу на курс, группа «Обучение»).
14. **Строка ссылки** хранит ссылку на элемент и комментарий. Это относится к задачам АП, задачам шаблонов и пунктам чек-листов.
15. **Поле «Ссылка»** в таблице «Ссылки для ознакомления»:
    - выпадающий список по группам: название и адрес;
    - отбор по мере ввода (по названию и адресу);
    - внизу — «+ Создать»;
    - в просмотре — гиперссылка с названием, адрес — в подсказке;
    - «Создать» над таблицей добавляет строку и сразу открывает список.
    - Клавиши: ↓ — к списку, Enter — первый найденный, Esc — закрыть.
16. **«+ Создать»** открывает форму «Библиотека ссылок (создание)»:
    - поля «Название» (подставляется введенный текст), «Группа», «Ссылка»;
    - проверки: ссылка обязательна, без пробелов и не повторяет существующую;
    - «Записать и закрыть» — элемент добавлен в справочник и сразу подставлен в строку.
17. **Пустая строка** без выбранной ссылки удаляется при сохранении. Строка с комментарием или введенным текстом дает ошибку «Выберите ссылку из библиотеки или удалите строку».

### 3.4. Тесты

18. **Добавлен тест f200.**
19. **Тесты прошлых фаз обновлены:**
    - all8, f83, f95, f103, f104, f116, f120 — отметка пунктов через «Выполнить» ответственного, карточку задачи или данные; флажок — индикатор `.cl-mark`;
    - ft2 — выбор ссылки из библиотеки;
    - f111 — части разделенной кнопки «Выполнить ▾» скруглены с одной стороны.

## 4. Что проверить заказчику

- Команды документов (форма заявки 0911, переход в Bitrix, Forus Team, СИТ) удалены из чек-листа полностью. Переход во внешние системы — через ссылки задачи. Если создание заявки 0911 из чек-листа нужно, вернем его отдельной задачей.
- Проверяющий «Вернуть на доработку» возвращает пункт в «В работе», как у задач АП.
