## 2. Подфаза 11.1. Новый стиль

### 2.1. Токены

Заменить и добавить в `:root`:

```css
/* Скругления */
--radius: 8px;          /* карточки, блоки, контейнеры таблиц, левая панель */
--radius-s: 6px;        /* кнопки, поля ввода, тумблеры */
--radius-pill: 10px;    /* бейджи */

/* Рамки блока аналитики */
--c-danger-border:  #F3C3BE;
--c-warning-border: #F2D9A0;
--c-info-border:    #BCD3FA;

/* Размеры шрифта */
--fs-s: 12px; --fs-m: 13px; --fs-l: 15px; --fs-xl: 20px;
--fw-bold: 600;
```

Остальные цветовые токены не меняются.

### 2.2. Общие правила

- **Полужирное начертание** — `--fw-bold` (600) вместо 700.
- **Кнопки:** высота 32px, скругление `--radius-s`. Основная — заливка `--c-primary`, белый текст. Обычная — белая, рамка `--c-border`.
- **Поля ввода** (поиск и другие): высота 32px, скругление `--radius-s`, иконка лупы слева в поле поиска.
- **Бейджи статусов задач АП:** скругление `--radius-pill`, 12px.
- **Иконки:**
  - в фильтрах левой панели — 18px;
  - в шапке стажёра перед подписями дат — 16px, `--c-text-secondary`;
  - в блоке аналитики — 16px.
- **Верхние вкладки кабинета:** 15px; активная — `--fw-bold` и подчёркивание 2px `--c-tab-active`.
- **Вкладки стажёра:** 14px; активная — `--fw-bold`, `--c-text` и подчёркивание 2px `--c-tab-active`; неактивная — обычное начертание, `--c-text-secondary`. Отменяет фазу 9, 4.4.
- **Заголовок окна:** слева кнопка «←» (заглушка навигации платформы, `data-1c="НЕ_ПЕРЕНОСИТЬ"`, `title="Назад"`), затем «Личный кабинет руководителя» 20px `--fw-bold`. Справа демо-переключатель, затем ⟳ ⋮ ✕.

### 2.3. Таблицы (отменяет фазу 9, 4.2)

Все таблицы: сводная, задачи АП, чек-листы, таблицы в диалогах.

- Контейнер с рамкой 1px `--c-border` и скруглением `--radius`, содержимое обрезается по скруглению.
- Строка заголовков: фон `--c-bg-panel`, текст `--fs-s` `--c-text-secondary`.
- Строки: высота минимум 36px, горизонтальные линии `--c-border`, вертикальных нет.
- Строка группировки (блоки в таблице задач): фон `--c-bg`, текст `--fw-bold`.
- Выбранная строка: фон `--c-bg-selected`.

| Фильтр | Кого показывает | Цвет иконки и числа |
|---|---|---|
| Требуют внимания | Стажёры с хотя бы одним замечанием danger или warning | `--c-danger` |
| **Просроченные** (новый) | Стажёры с хотя бы одной просрочкой **где угодно**: задачи АП, пункты подготовки, пункты закрытия | `--c-danger` |

- Активная строка — фон `--c-bg-selected`, подпись `--fw-bold`, после числа «✕».

### 3.3. Дерево

- Белый контейнер с рамкой `--c-border` и скруглением `--radius`, растягивается на оставшуюся высоту.
- Колонки как в фазе 9, 7.2: наименование | статус (иконка danger/warning) | количество.
- У выбранного стажёра в колонке количества — шеврон «›» `--c-text-secondary`.

## 4. Подфаза 11.3. Карточка стажёра

### 4.1. Раскладка

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ ┌──┐ Иванов Петр Сергеевич         │ Наставник              │ Руководитель            │ 📅 Даты стажировки 29.07.26 – 28.10.26 │

│ └──┘ Аналитик, А2                  │ Андреевич              │ Евгеньевна              │                                         │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- Белая карточка, рамка `--c-border`, скругление `--radius`, отступы 16px. Части разделены вертикальными линиями `--c-border`.
- **Аватар** 56px, круг с инициалами, фон `--c-info-bg`, текст `--c-primary`.
- **Имя и должность** — три строки:
  1. ФИО — `--fs-xl`, `--fw-bold`. **Бейджа рядом нет.**
  2. Подразделение — гиперссылка. Клик открывает карточку подразделения (заглушка: оповещение «Откроется карточка подразделения „…“»). Обычная гиперссылка, `--fs-m`.
  3. Должность и квалификационный уровень через запятую: «Аналитик, А2». Если уровня нет — только должность, без запятой. `--c-text-secondary`.

- **Даты** — строки с иконками 16px слева:
  - календарь — «Даты стажировки ДД.ММ.ГГ – ДД.ММ.ГГ»;
  - часы — вторая строка по этапу (фаза 10, 2.2): «Выход через N дней» (`--fw-bold`), «До закрытия: N дней» или «Стажировка закрыта / отменена ДД.ММ.ГГ»;
  - при `lag` третья строка «Задачи отстают от графика» цветом `--c-warning`, без иконки, с отступом под текст.
- Полосы прогресса в карточке **не показываются**.
- Кнопок в карточке нет. «Продлить срок» и «Отозвать с согласования» из фазы 10 убираются (см. раздел 5).

### 4.2. Квалификационный уровень

В `data.js` у стажёра добавляются поля:

```js
positionFamily   // 'analyst' | 'programmer' | 'erp_analyst' | null
qualificationLevel // строка или null
```

| `positionFamily` | Допустимые уровни |
|---|---|
| `analyst` | А1–А7 (кириллическая «А») |
| `programmer` | П1–П7 |
| `erp_analyst` | AERP1–AERP5 (латиница) |
| `null` | Уровень не выводится |

Других маркировок не добавлять. Функция `formatPosition(trainee)` проверяет, что уровень из допустимого диапазона семейства. Если уровень недопустимый — выводится только должность и пишется предупреждение в консоль.

Тестовые данные:

| Стажёр | Должность | Семейство | Уровень |
|---|---|---|---|
| Иванов | Аналитик | `analyst` | А2 |
| Кузнецова | Аналитик | `analyst` | А4 |
| Попова | Аналитик | `analyst` | А5 |
| Белова | Программист | `programmer` | П2 |
| Сидоров | Аналитик ERP | `erp_analyst` | AERP3 |
| Лебедев, Орлова, Смирнов | Без изменений | `null` | — |

Должность с уровнем выводится так же в сводной таблице — во второй строке колонки «Стажёр».

## 5. Подфаза 11.4. Блок «Аналитика по адаптационной программе»

Работает как в фазе 10 (сворачиваемый, со счётчиком, по умолчанию свёрнут, состояние сохраняется между стажёрами до перезагрузки). Меняются вид, содержимое и кнопки.

### 5.1. Вид

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ ▾ (!) Аналитика по адаптационной программе (2)             [Создать АП]                     │
│       ● 1 просроченный пункт подготовки к выходу                                            │
│       ⚠ Не создана адаптационная программа                                                  │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Рамка и заливка** — по самому критичному замечанию: рамка 1px, скругление `--radius`, отступы 12px 16px.

| Самое критичное замечание | Фон | Рамка | Иконка в заголовке |
|---|---|---|---|
| danger (просрочки) | `--c-danger-bg` | `--c-danger-border` | круг с «!», `--c-danger` |
| warning (предупреждения) | `--c-warning-bg` | `--c-warning-border` | треугольник, `--c-warning` |
| info (информирующие) | `--c-info-bg` | `--c-info-border` | круг с «i», `--c-info` |
| Замечаний нет | `--c-bg` | `--c-border` | нет иконки |

- **Строка заголовка:**
  - стрелка ▸/▾ стоит **рядом с заголовком, слева**, как было;
  - далее иконка, текст «Аналитика по адаптационной программе (N)» — `--fs-l`, `--fw-bold`, `--c-text`;
  - справа — кнопки действий (5.3). **Они в строке заголовка и видны в свёрнутом блоке.**
  - Стрелки «›» у правого края нет.
- **Содержимое** (в развёрнутом виде): **каждое замечание — отдельной строкой**, без разделителей. Строка 28px: иконка 16px по типу (danger — залитый кружок, warning — треугольник, info — круг с «i»), текст `--c-text`. **Кнопок у строк нет.** Отступ слева — под текст заголовка.
- При N = 0 стрелка не показывается, блок не раскрывается, в заголовке «(0)». Блок виден, если есть кнопки действий (5.3). Если нет ни замечаний, ни кнопок (этап `closed`) — блок скрыт.

В 1С: цвет фона и рамки группы задаётся программно по самому критичному замечанию.

### 5.2. Замечания (заменяет таблицу фазы 10, 3.4)

Порядок: danger → warning → info, внутри уровня — в порядке таблицы. Тексты — со склонением через `plural()`.

| id | Уровень | Текст |
|---|---|---|
| `prep_overdue` | danger | N просроченный пункт / просроченных пункта / просроченных пунктов подготовки к выходу |
| `tasks_overdue` | danger | N просроченная задача / просроченные задачи / просроченных задач адаптационной программы |
| `closure_overdue` | danger | N просроченный пункт / … закрытия стажировки |
| `no_program` | warning | Не создана адаптационная программа. Выход через N дней |
| `draft_stale` | warning | Адаптационная программа не отправлена на согласование уже N дней |
| `rejected` | warning | Адаптационная программа возвращена на доработку: «комментарий» |
| `changed_after_approval` | warning | Адаптационная программа изменена после согласования |
| `lag` | warning | Задачи отстают от графика: выполнено X% при прошедших Y% срока |
| `close_soon` | info | До окончания стажировки N дней, пора начинать закрытие. Только при `active` с ≤ `CLOSE_AVAILABLE_DAYS` дней |
| `closure_ready` | info | Все обязательные пункты закрытия выполнены |

Счётчик N — число замечаний. Дерево, «Требуют внимания» и счётчик вкладки верхнего уровня считаются по danger и warning, как раньше.

### 5.3. Кнопки действий

Набор кнопок определяется стадией стажировки. Кнопки идут в порядке таблицы, показываются все подходящие строки.

| Условие | Кнопка | Что делает |
|---|---|---|
| АП нет | **Создать АП** | Открывает вкладку АП с пустым состоянием (основное ТЗ 7.5.5) |
| АП в черновике, возвращена на доработку или `changedAfterApproval` | **Отправить на согласование** | Диалог отправки (основное ТЗ 7.7) |
| `active` и до окончания ≤ `CLOSE_AVAILABLE_DAYS` дней | **Начать закрытие стажировки** | См. 5.4 |
| `approval` | Открыть лист согласования | Оповещение-заглушка «Откроется лист согласования» |
| `active`, `closing` | Продлить стажировку | Диалог «Продлить срок» (основное ТЗ 7.7, заголовок и кнопка — «Продлить стажировку») |
| `active`, `closing` | Отменить стажировку | Диалог отмены (основное ТЗ 7.7). Обычная кнопка, текст `--c-danger` |

- Основной становится первая показанная кнопка из выделенных полужирным. Остальные — обычные.
- Примеры: у Орловой — «Отправить на согласование» (основная), «Продлить стажировку», «Отменить стажировку»; у Смирнова — «Продлить стажировку», «Отменить стажировку».
- «Отменить стажировку» остаётся и в меню ⋮, как было.
- «Отправить на согласование» из командной панели вкладки АП (фаза 10, 2.1) **удаляется**.

### 5.4. Начало закрытия (отменяет фазу 10, 5.1, в части автоперехода)

- **Автоматического перехода в `closing` больше нет.**
- «Начать закрытие стажировки» открывает подтверждение «Начать закрытие стажировки? Появится вкладка с чек-листом закрытия». По подтверждению:
  - этап → `closing`;
  - создаётся чек-лист закрытия (фаза 10, 5.2), если его нет;
  - появляется и открывается вкладка «Закрытие стажировки»;
  - запись в историю;
  - оповещение «Закрытие стажировки начато».
- Если продление увело `endDate` дальше порога при этапе `closing`, этап возвращается в `active`, как в фазе 10.
- «Завершить стажировку» остаётся в командной панели вкладки закрытия (фаза 10, 5.3–5.4).
- Демо-переключатель при переводе в «Закрытие» делает то же, что кнопка. Правило фазы 10, 6 про «перевод в `active` не проходит» удаляется.

## 6. Подфаза 11.5. Вкладка «Адаптационная программа»

### 6.1. Порядок элементов

```
Проверяющий по умолчанию: …     Наблюдатели по умолчанию: …     Изменить
[+ Добавить ▾]  [Печать АП]                     Выбрано: 2  [Действия с выбранными ▾]  Снять выделение
[Все 20 | Просрочено 1 | В работе 2 | Не начато 4 | Выполнено 13]
┌ таблица ─────────────────────────────────────────────────────────┐
```

### 6.2. Группы блоков

- При открытии вкладки (переход на неё или выбор стажёра) **обе группы свёрнуты**.
- Строка группы в свёрнутом виде: «▸ Корпоративный блок», «выполнено X из Y», мини-полоса.

### 7.2. Колонки

| Колонка | Содержимое |
|---|---|
| ☐ | Флажок выполнения, как было |
| Пункт | Наименование. У необязательного пункта закрытия второй строкой «необязательно» |
| Ответственный | **Только ФИО полностью, без роли.** Если пункт выполнил другой человек — второй строкой серым «Выполнил: ФИО» |
| Срок | Первая строка — дата. Вторая строка: «за N дн. до выхода» / «за N дн. до окончания» / «в день окончания» / «через N дн. после окончания». У невыполненного просроченного пункта — «просрочено на N дн.», дата и текст `--c-danger` |
| **Дата выполнения (факт)** | Дата `ДД.ММ.ГГ` для выполненных пунктов; пусто для невыполненных |
| Действие | Как было (основное ТЗ 7.6, фаза 10, 5.3) |

- Колонки «Статус» нет, статусов пунктов нет.
- Под наименованием пункта никаких «Выполнено …» нет.
